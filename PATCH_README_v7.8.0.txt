Liangshan v7.8.0 update-only package

這是從 v7.7.0 升級到 v7.8.0 的「只含需要更新檔案」壓縮檔。

使用方式：
1. 先備份你原本的 Liangshan_v7.7.0 資料夾與遊戲存檔。
2. 將本 ZIP 解壓到 v7.7.0 的網站根目錄。
3. 遇到同名檔案請選擇「覆蓋」。
4. 重新整理瀏覽器；若是 GitHub Pages，請重新部署並等待 Actions 完成。
5. 開啟遊戲後確認首頁顯示 v7.8.0。

本更新包包含：核心檔案、v7.8 新模組、精修重要英雄立繪、新增遠征首領立繪、文件與檢查清單。
不包含未變更的 v7.7.0 基礎檔案。
