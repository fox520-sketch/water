Liangshan v7.5.0 Windows 版

1. 在 Liangshan_v7.5.0_Windows.zip 上按滑鼠右鍵。
2. 選擇「全部解壓縮」。
3. 進入 Liangshan_v7.5.0 資料夾。
4. 雙擊 index.html 開始遊戲。
5. 不想解壓縮時，可直接開啟 Liangshan_v7.5.0_Standalone.html。

注意：
- 直接開啟 HTML 可遊玩，但 PWA、Service Worker 與 Firebase 建議部署至 GitHub Pages 或 localhost。
- 請定期使用遊戲內的存檔匯出功能備份 JSON。
- Firebase 設定請看 FIREBASE_SETUP.md。
- 正式上線檢查請看 LIVE_DEPLOYMENT_CHECKLIST.md。
