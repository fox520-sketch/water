## 六、測試環境說明

執行環境的 Chromium 管理政策會阻擋 `localhost`、自訂測試網域與 `file://` 導覽，因此完整介面測試採用「將正式 HTML、CSS、JavaScript 原樣內嵌至 Chromium 測試頁」方式執行。此方式已驗證實際 DOM、按鈕事件、戰鬥、軍略、結算、響應式版面與存檔序列化；Service Worker 則以語法、快取清單、Manifest 與圖示進行靜態檢查。
