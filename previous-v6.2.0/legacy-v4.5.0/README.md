# 水滸英雄傳：梁山風雲 v4.5.0

章回式單機網頁 RPG。本版延續 v4.4.0 的百藥安採制度，新增第三十四回「出林龍驗泉・百水安飲」，讓梁山公共治理由藥材安全延伸至泉井、水源、煮沸封存與停水補給。

## v4.5.0 新增內容

- 第三十四名主角「出林龍・鄒淵」
- 新同伴「獨角龍・鄒潤」與援護技能「獨角龍護井」
- 鄒淵雙技能：「出林龍驗泉」與「四源安飲」
- 第三十四回完整主線：泉井污染、霸井哄價、生熟水混裝、髒桶封存與停水斷供
- 四項查驗：泉井界源、驗水煮沸、淨桶封存、緊急供水
- 五階段軍略：「界源分流、巡檢驗水、煮沸淨置、淨桶封存、停水補給」
- 三場主線戰鬥與「百水安飲演武場」重複挑戰
- 四個新地點：泉井檢驗場、百水安飲署、安心取水站、百水安飲演武場
- 新裝備與制度物品：巡泉長槍、百水安飲衣、水源巡檢總冊、驗水煮沸與停水補給簿、百水安飲約
- 梁山建設新增「百水安飲署」，可強化新章回軍勢與演練
- 三十四英雄譜、三十四名同伴資料、章回總結、遊戲指南與版本說明同步更新

## 相容性與存檔

- 支援 v1.0.0～v4.4.0 舊存檔自動升級
- 舊存檔會自動補入鄒淵英雄資料、鄒潤同伴資料、專屬裝備、第三十四回任務、旗標與百水安飲署
- v4.4.0 已完成第三十三回的存檔，可直接從章回結尾或百藥安採演武場開啟第三十四回
- 存檔仍保存在目前瀏覽器的 `localStorage`；更換瀏覽器、裝置或清除網站資料前請先匯出存檔

## 執行方式

直接開啟 `index.html` 即可遊玩。若要啟用完整 PWA、離線快取及安裝功能，建議放在 GitHub Pages 或其他 HTTPS 靜態網站。

Service Worker 快取名稱：`liangshan-rpg-v4.5.0`。

## 主要檔案

- `index.html`：頁面、模板與 PWA 中繼資料
- `styles.css`：桌面、手機、深色與黑白電子紙顯示樣式
- `game.js`：角色、章回、戰鬥、軍略、存檔遷移與介面邏輯
- `manifest.webmanifest`：PWA 資訊
- `service-worker.js`：離線快取與更新
- `TEST_REPORT.md`：本版測試結果
