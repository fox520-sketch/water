第五十回「催命判官察店・百旅安宿」

- 第五十名主角：催命判官・李立
- 新同伴：混江龍・李俊
- 主角技能：催命判官斷黑、百旅安宿
- 同伴援護：混江龍截浪
- 四項查驗：旅簿與去向、酒食與藥物、旅資與寄存、夜巡與救濟

- 三場主線戰鬥、章回結算、五十英雄譜、第三十五至五十回章回錄

## v6.1.0 新功能

- 故事、標準、豪傑三種難度
- 敵方氣血、攻擊與銀兩獎勵隨難度調整
- 四項章回成就：明察秋毫、三戰連捷、清醒到底、判官獨守
- 自動承接 v6.0.0 第四十九回完成紀錄與部分銀兩

## 開啟方式

直接開啟根目錄 `index.html`。部署到 GitHub Pages 後可安裝為 PWA。

## 存檔與前版保留

- v6.1.0 續篇存檔：`liangshan-rpg-sequel-v6`
- v6.0.0 前回備份：`liangshan-rpg-sequel-v6.0-backup`
- 經典篇存檔：`liangshan-rpg-save-v1`，新版只讀不覆寫
- 可由遊戲內匯出／匯入 JSON
- `previous-v6.0.0/`：可獨立重遊第四十九回
- `legacy-v4.5.0/`：完整保留經典篇

## 顯示與裝置

支援桌面、手機、水墨／深色／電子紙模式、語音朗讀與離線 PWA。
