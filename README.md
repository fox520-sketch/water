## 安裝與執行

### 本機直接開啟

解壓縮後可嘗試直接開啟 `index.html`。為確保 PWA、Service Worker 與語音相關功能正常，建議以本機 HTTP 伺服器執行：

```bash
python -m http.server 8080
```

再開啟 `http://localhost:8080/`。

### GitHub Pages

將下列檔案與資料夾直接放在儲存庫根目錄：

```text
index.html
styles.css
game.js
manifest.webmanifest
service-worker.js
README.md
TEST_REPORT.md
assets/
```

不要只上傳外層資料夾，否則 GitHub Pages 可能找不到 `index.html`。

## 存檔與更新

- 存檔鍵：`liangshan-rpg-save-v1`
- 設定鍵：`liangshan-rpg-prefs-v1`
- 更新檔案後，舊進度會由程式自動補入新英雄、任務、同伴、建築及旗標。
- 清除瀏覽器網站資料、無痕模式結束或更換裝置，可能使本機存檔消失。

## 文學改編說明

本作以《水滸傳》人物與重要情節為基礎，加入 RPG 戰鬥、軍略數值、角色切換與分歧選項。部分事件為遊戲化重組，不是原著逐字重現；聚義座次也只針對目前九名可操控英雄的遊戲職司設計。
