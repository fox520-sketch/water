# 水滸英雄傳：梁山風雲 v4.2.0

章回式單機網頁 RPG。本版延續 v4.1.0 的水泊百市保真制度，新增第三十一回「小尉遲巡倉與百糧安儲」，完成三十一英雄與公共糧儲系統。

## v4.2.0 新增內容

- 第三十一名主角「小尉遲・孫新」
- 專屬技能「小尉遲巡倉」「四倉安儲」
- 新同伴「雙頭蛇・解珍」及援護「雙頭蛇探倉」
- 四項安儲線索：糧源批次、含水霉蟲、倉位輪儲、災備放糧與補償
- 三場主線戰鬥及五階段「水泊百糧安儲」軍略
- 新建築「梁山百糧公儲署」
- 四處新地點：糧貨驗收場、百糧公儲署、安心糧市、百糧安儲演武場
- 三項收藏：水泊百糧溯源總冊、驗糧輪儲與災備放糧簿、水泊百糧安儲約
- 支援 v1.0～v4.1.0 舊存檔自動升級

## 部署

解壓縮後，將 `index.html`、`game.js`、`styles.css`、`manifest.webmanifest`、`service-worker.js`、`assets` 與其餘文件直接上傳至 GitHub Pages 儲存庫根目錄。更新後請按 `Ctrl + F5` 強制重新整理。

Service Worker 快取名稱：`liangshan-rpg-v4.2.0`。
