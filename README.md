# 水滸英雄傳：梁山風雲 v4.6.0

章回式單機網頁 RPG。本版延續 v4.5.0 的百水安飲制度，新增第三十五回「獨角龍疏渠・百田安灌」，讓梁山公共治理由安全飲水延伸至農田灌溉、排水、防洪抗旱與災後復耕。

## v4.6.0 新增內容

- 第三十五名主角「獨角龍・鄒潤」
- 新同伴「九尾龜・陶宗旺」與援護技能「九尾龜固堤」
- 鄒潤雙技能：「獨角龍疏渠」與「四田安灌」
- 第三十五回完整主線：霸渠截水、私閘偏灌、淤塞潰堤、旱澇失序與災後吞田
- 四項查驗：渠源田界、閘口配水、清淤固堤、旱澇補種
- 五階段軍略：「渠源分界、閘口配水、清淤固堤、旱澇輪灌、災後補種」
- 三場主線戰鬥與「百田安灌演武場」重複挑戰
- 四個新地點：田渠踏勘場、百田安灌署、安心灌田口、百田安灌演武場
- 新裝備與制度物品：獨角龍疏渠鐵角、百田安灌衣、田渠界源配水總冊、清淤固堤與旱澇補種簿、百田安灌約
- 梁山建設新增「百田安灌署」，可強化新章回軍勢與演練
- 三十五英雄譜、三十五名同伴資料、章回總結、遊戲指南與版本說明同步更新

## 相容性與存檔

- 支援 v1.0.0～v4.5.0 舊存檔自動升級
- 舊存檔會自動補入鄒潤英雄資料、陶宗旺同伴資料、專屬裝備、第三十五回任務、旗標與百田安灌署
- v4.5.0 已完成第三十四回的存檔，可直接從章回結尾或百水安飲演武場開啟第三十五回
- 存檔仍保存在目前瀏覽器的 `localStorage`；更換瀏覽器、裝置或清除網站資料前請先匯出存檔

## 執行方式

直接開啟 `index.html` 即可遊玩。若要啟用完整 PWA、離線快取及安裝功能，建議放在 GitHub Pages 或其他 HTTPS 靜態網站。

Service Worker 快取名稱：`liangshan-rpg-v4.6.0`。

## 主要檔案

- `index.html`：頁面、模板與 PWA 中繼資料
- `styles.css`：桌面、手機、深色與黑白電子紙顯示樣式
- `game.js`：角色、章回、戰鬥、軍略、存檔遷移與介面邏輯
- `manifest.webmanifest`：PWA 資訊
- `service-worker.js`：離線快取與更新
- `TEST_REPORT.md`：本版測試結果
