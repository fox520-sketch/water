# 水滸英雄傳：梁山風雲 v1.3.0

以《水滸傳》章回故事改編的單機網頁 RPG。純 HTML、CSS、JavaScript 製作，不需要安裝套件、伺服器或資料庫，可直接部署至 GitHub Pages。

## v1.3.0「第二回・拳打鎮關西」

本版在第一回「景陽岡武松打虎」之外，新增完整第二回：

- 潘家酒樓與九紋龍史進相會
- 聽聞金翠蓮父女受欺
- 護送金氏父女離開投店
- 狀元橋三道肉單消遣鄭屠
- 首領戰「鎮關西鄭屠」
- 魯提轄逃離渭州
- 五臺山剃度，取得法名「智深」

## 新增系統

- 武松、魯達／魯智深雙主角
- 完成第二回後自由切換英雄
- 每位主角獨立保存等級、氣血、豪氣、義氣、銀兩與裝備
- 兩位主角共用行囊與江湖同伴
- 魯智深專屬技能：
  - 禪杖橫掃
  - 金剛怒喝
- 新同伴「九紋龍・史進」
- 史進助陣技能「九紋龍突擊」
- 新敵人：投店惡僕、鎮關西鄭屠、渭州棒師
- 鄭屠疲勞機制：完成越多肉單，首領戰越有利
- 新地點：渭州城、狀元橋肉案、五臺山
- 英雄譜與雙章回成果統計
- 新裝備與重要信物：渭州鐵棍、水磨禪杖、皂布僧衣、金氏銀釵、五臺度牒

## 保留功能

- 第一回「景陽岡武松打虎」
- 章回式劇情與義氣選擇
- 回合制戰鬥
- 宋江、柴進、史進同伴編成與羈絆
- 陽谷擂臺與五臺演武
- 裝備、道具、任務與本機存檔
- 可選語音播報、語速與音量設定
- 水墨、深色、黑白電子紙三種顯示模式
- 手機、平板與桌機響應式介面
- PWA 安裝與離線快取

## 舊存檔相容

v1.0、v1.1、v1.2 的 LocalStorage 存檔可直接讀取。舊版武松資料會自動轉入新的雙主角結構；不需要重玩第一回。

存檔仍使用：

```text
liangshan-rpg-save-v1
```

## 本機遊玩

可直接開啟 `index.html`。語音播報可用性依瀏覽器與作業系統而異。

PWA 與 Service Worker 必須透過 HTTPS 或本機網頁伺服器測試；直接以 `file://` 開啟時不會註冊 Service Worker。

## GitHub Pages 部署

將下列內容直接放在儲存庫根目錄：

```text
index.html
styles.css
game.js
manifest.webmanifest
service-worker.js
README.md
TEST_REPORT.md
assets/
```

不要只上傳外層 `water-margin-rpg-v1.3.0` 資料夾，否則 GitHub Pages 可能找不到根目錄的 `index.html`。

更新後若仍顯示舊版，請重新整理兩次，或關閉已安裝的 PWA 再重新開啟，讓新版 Service Worker 接管快取。

## 技術與授權提醒

故事取材自中國古典小說《水滸傳》，場景、對話、支線、介面與程式均為本遊戲的重新設計。請勿直接加入現代影視、漫畫或其他遊戲的角色圖像、配樂與介面素材。
