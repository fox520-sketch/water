# 水滸英雄傳：梁山風雲 v4.1.0

章回式單機網頁 RPG，以《水滸傳》人物與事件為基礎進行互動式改編。本版延續 v4.0.0 的水泊百包安寄制度，新增第三十回「母大蟲驗貨與百市保真」，完成三十英雄與市貨公驗系統。

## v4.1.0「第三十回・母大蟲驗貨與百市保真」

- 新增第三十名主角「母大蟲・顧大嫂」
- 新增顧大嫂技能「母大蟲驗貨」與「四市保真」
- 新增同伴「小尉遲・孫新」及援護技能「小尉遲巡市」
- 新增貨源批次、真樣品質、尺秤價牌、退換理賠四項市貨線索
- 新增五階段「水泊百市保真」軍略
- 新增假貨封市巡丁、短秤牙行護院、貨利掮客與假貨豪商等敵人
- 新增「梁山市貨公驗局」及四處輿圖地點
- 新增「百市失序／公開百市保真」分歧劇情
- 新增三項章回收藏及百市保真演武場
- 三十位英雄可於完成各自章回後自由切換

## 本版修正

- 補齊顧大嫂在英雄切換、章回編號、返回據點與輿圖旅行的判定
- 補上第 29、30 回調查線索對敵人攻防的實際削弱
- 完整調查四項市貨線索後，可依正確順序完成公開退換與賠償
- 更新遊戲指南、版本介紹、總成果、聚義座次及梁山建設
- 統一首頁、Manifest、Service Worker 與 PWA 快取為 v4.1.0

## 遊戲特色

- 三十回完整主線與三十名可操作英雄
- 回合制戰鬥、角色專屬技能及同伴援護
- 調查線索、軍略推演、分歧劇情及重複演武
- 梁山建設、英雄譜、江湖輿圖、快速整備及本機存檔
- 水墨宣紙、深色及黑白電子紙三種顯示模式
- 可選語音播報與 PWA 離線遊玩
- 純 HTML、CSS、JavaScript，不需要資料庫或後端伺服器

## GitHub Pages 部署

1. 解壓縮 ZIP。
2. 將 `index.html`、`game.js`、`styles.css`、`manifest.webmanifest`、`service-worker.js`、說明文件及 `assets` 資料夾直接上傳至儲存庫根目錄。
3. 不要只上傳外層 `water-margin-rpg-v4.1.0` 資料夾，否則 GitHub Pages 可能找不到首頁。
4. 發布後按 `Ctrl + F5` 強制重新整理。

## PWA 快取

Service Worker 快取名稱為 `liangshan-rpg-v4.1.0`。覆蓋新版檔案後請強制重新整理；若已安裝為 PWA，請完全關閉後重新開啟，以載入新版快取。

## 舊存檔升級

v4.1.0 會自動補齊母大蟲顧大嫂主角、小尉遲孫新、第三十回任務、市貨公驗局、四項市貨線索及百市軍略欄位。舊版英雄、裝備、同伴、建築與章回進度均會保留。

存檔使用瀏覽器 LocalStorage；清除網站資料或更換瀏覽器、裝置，不會自動同步原有進度。
