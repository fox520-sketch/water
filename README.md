# 水滸英雄傳：梁山風雲 v7.5.0

## 百八真傳與正式上線版

本版在 v7.4.0 的 108 回主線、速度回合、裝備、山寨、遠征與雲端基礎上，完成 72 地煞獨立資料、重要章回手工劇情、Rogue-like 遠征、每週挑戰、雲端版本歷史與智慧合併。

## 遊玩方式

### Windows ZIP

1. 解壓縮 `Liangshan_v7.5.0_Windows.zip`。
2. 進入 `Liangshan_v7.5.0` 資料夾。
3. 雙擊 `index.html`。

直接以檔案開啟時可遊玩，但完整 PWA、Service Worker、IndexedDB 與 Firebase 功能建議部署至 GitHub Pages 或 localhost。

### 免解壓版本

直接開啟 `Liangshan_v7.5.0_Standalone.html`。此版本內嵌 CSS 與 JavaScript，不包含 PWA 安裝與 Service Worker。

## v7.5.0 主要功能

### 108 英雄真傳

- 36 天罡沿用手工專屬技能機制。
- 72 地煞各有獨立技能、被動、覺醒、冷卻與唯一機制簽章。
- 72 地煞以 12 種主機制與 6 種副機制組成 72 套不重複戰法。
- 英雄專屬裝備會限制給對應英雄使用。

### 重要章回手工劇情

12 個重要章回改為手工內容：第 1、2、3、5、9、10、14、15、16、21、28、108 回。

每回包含：

- 專屬開場文字。
- 三條主方案。
- 專屬判斷關卡。
- 成功、補救及不同主方案結局。
- 章回評分與成就差異。

其他章回仍保留資料驅動流程與分支結局。

### Rogue-like 與每週挑戰

- 每次生成九節點隨機路線。
- 節點包含戰鬥、精英、事件、休息、商店及終局首領。
- 遠征中可取得遺物與一次性增益。
- 容錯耗盡才會結束本次遠征，不影響主線。
- 每週依週次產生不同章回與限制條件。

### 雲端傳承

- Firebase Email/Password 登入。
- Firestore 主存檔與版本歷史。
- 本機／雲端欄位比較。
- 智慧合併章回、英雄、裝備、建設與長期紀錄。
- 套用雲端前自動建立本機備份。
- 未設定 Firebase 時仍可完全離線遊玩。

### 戰鬥平衡與統計

- 記錄戰鬥數、勝敗、平均回合及英雄使用情形。
- 內建 500 組快速平衡模擬。
- `BALANCE_REPORT.md` 提供本次發布前模擬摘要。

### 裝備與派遣

- 六部位裝備、套裝、重鑄與鍛造保底。
- 批次選取及批次分解。
- 108 名英雄專屬裝備。
- 派遣適性會影響獎勵。
- 派遣可能觸發奇遇。
- 離線生產最多累積 24 小時，並防止系統時間倒退重複領取。

### 無障礙與效能

- 高對比、四級字體、減少動畫、低效能模式。
- 螢幕閱讀器模式與限制範圍的即時朗讀。
- 彈窗焦點鎖定、Esc 關閉與跳至主要內容。
- 英雄與裝備清單分頁，低效能模式會縮小每頁項目數。
- 390 × 844 手機畫面通過水平溢位檢查。

## 存檔

- IndexedDB 主存檔。
- localStorage 相容鏡像。
- Schema v5 驗證與校驗碼。
- 最近十份輪替備份。
- 可匯出及匯入 JSON。
- 可承接 v7.4.0 的章回、英雄、裝備、建設、編隊、銀兩與長期紀錄。

## 部署與驗收

- `DEPLOY_GITHUB_PAGES.md`：GitHub Pages 部署。
- `FIREBASE_SETUP.md`：Firebase 設定與跨裝置步驟。
- `LIVE_DEPLOYMENT_CHECKLIST.md`：公開網站及真實 Firebase 驗收。
- `SCREEN_READER_CHECKLIST.md`：NVDA、VoiceOver、TalkBack 真人驗收。
- `PWA_ACCEPTANCE.md`：本發布環境可完成與尚待完成的 PWA 項目。

## 驗收界線

本版已完成本機瀏覽器、自動化、模擬 Firebase REST、ZIP 及靜態發布檢查。由於製作環境沒有你的 GitHub 儲存庫與 Firebase 專案寫入權限，也無法代替真人使用 NVDA／VoiceOver／TalkBack，因此下列項目仍需部署後完成：

- 公開 GitHub Pages 網址。
- 真實 Firebase 電腦／手機跨裝置同步。
- 不同帳號 Rules 隔離測試。
- 真人螢幕閱讀器操作驗收。
