# 水滸英雄傳：梁山風雲 v3.5.0

章回式單機網頁 RPG，以《水滸傳》人物與事件為基礎進行互動式改編。本版延續 v3.4.0 的水泊百工安作，新增第二十四回「金錢鍛準與百器公檢」。

## v3.5.0「第二十四回・金錢鍛準與百器公檢」

- 新增第二十四名可操作英雄「金錢豹子・湯隆」
- 新增湯隆專屬技能「金錢鍛準」與「百器公檢」
- 新增同伴「轟天雷・凌振」及援護技能「轟天驗聲」
- 新增材料爐次、主量規、召回修換、軍民器具流向四項線索
- 新增五階段「水泊百器公檢」軍略
- 新增三場第二十四回主線戰鬥及百器公檢演武
- 新增「梁山百器公檢所」與四處輿圖地點
- 新增材料追溯、危險召回與公檢新約三項收藏
- 新增百器失準與公開公檢分歧路線
- 二十四位英雄自由切換
- 完整保留 v1.0～v3.4.0 舊存檔

## 執行方式

直接開啟 `index.html` 即可遊玩。為確保 PWA、語音與離線快取正常，建議透過 GitHub Pages 或本機 HTTP 伺服器執行。

## GitHub Pages 部署

1. 解壓縮 ZIP。
2. 將 `index.html`、`game.js`、`styles.css`、`manifest.webmanifest`、`service-worker.js`、說明文件及 `assets` 資料夾直接上傳至儲存庫根目錄。
3. 不要只上傳外層 `water-margin-rpg-v3.5.0` 資料夾，否則 GitHub Pages 可能找不到首頁。
4. 部署後按 `Ctrl + F5` 強制重新整理。

## PWA 快取

Service Worker 快取名稱為 `liangshan-rpg-v3.5.0`。覆蓋新版檔案後請強制重新整理；若已安裝為 PWA，請完全關閉後重新開啟，以載入新版快取。

## 舊存檔升級

v3.5.0 會自動補齊湯隆、凌振、第二十四回任務、百器公檢所、公檢線索及軍略欄位。舊版英雄、裝備、同伴、建築與章回進度均會保留。
