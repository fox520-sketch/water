# 水滸英雄傳：梁山風雲 v4.3.0

章回式單機網頁 RPG。本版延續 v4.2.0 的水泊百糧安儲制度，新增第三十二回「雙頭蛇辨跡與百林共護」，完成三十二英雄與公共山林巡護系統。

## v4.3.0 新增內容

- 第三十二名主角「雙頭蛇・解珍」
- 專屬技能「雙頭蛇辨跡」「四嶺共護」
- 新同伴「雙尾蠍・解寶」及援護「雙尾蠍清陷」
- 四項百林線索：山林地界與禁獵季、獸徑陷阱與毒餌、水源林火與伐木量、人獸救援與損失補償
- 三場主線戰鬥及五階段「水泊百林共護」軍略
- 新建築「梁山山林共護署」
- 四處新地點：山貨查驗場、山林共護署、共護山口、百林共護演武場
- 三項收藏：水泊山林地界總冊、清陷護水與救援補償簿、水泊百林共護約
- 支援 v1.0～v4.2.0 舊存檔自動升級

## 同步修正

- 補齊舊存檔遷移中的解珍英雄、裝備、解寶同伴與百林軍略狀態
- 補齊解珍在英雄譜中的名稱、據點、解鎖提示、章回完成判定與切換說明
- 更新遊戲指南、版本介紹、三十二英雄與三十二名同伴說明
- 更新首頁、Manifest 與 PWA 離線快取

## 部署

解壓縮後，將 `index.html`、`game.js`、`styles.css`、`manifest.webmanifest`、`service-worker.js`、`assets` 與其餘文件直接上傳至 GitHub Pages 儲存庫根目錄。更新後請按 `Ctrl + F5` 強制重新整理。

Service Worker 快取名稱：`liangshan-rpg-v4.3.0`。
