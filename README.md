# 水滸英雄傳：梁山風雲 v3.4.0

章回式單機網頁 RPG，以《水滸傳》人物與事件為基礎進行互動式改編。本版延續 v3.3.0 的水泊百舸共運，新增第二十三回「通臂織護與百工安作」。

## v3.4.0「第二十三回・通臂織護與百工安作」

公共舟運帶動造船、修械與旗幟工坊趕造，部分黑坊卻偽造工牌、堵塞火道、剋扣護具、強迫超時並隱匿工傷。侯健丈量護具與逃生路線，湯隆鍛造護面、護腕與防火鐵件，梁山將建立公開工時工價、輪班休息、工傷救護及事故賠償制度。

### 本版新增

- 第二十三名可操作英雄「通臂猿・侯健」
- 侯健專屬技能「通臂裁陣」與「百工護旗」
- 新同伴「金錢豹子・湯隆」及援護技能「金錢護具」
- 四項安作線索：護具尺寸與領用、工棚火道、工時工價輪班、工傷救護賠償
- 五階段「水泊百工安作」軍略
- 三場第二十三回主線戰鬥及百工安作演武
- 新建築「梁山百工安作院」
- 四處新地點：金沙灘百工驗具場、梁山百工安作院、水泊安作工坊街、百工安作演武場
- 三項新收藏：水泊百工護具總冊、工時工價與工傷簿、水泊百工安作約
- 二十三位英雄自由切換
- 支援 v1.0～v3.3.0 舊存檔自動升級

## 遊戲特色

- 23 個章回與 23 名可操作英雄
- 每位英雄具備專屬能力、裝備與返場演武地點
- 同伴羈絆、裝備、消耗品、山寨建設與快速整備
- 分歧劇情、戰敗重整及章回軍略
- 深色、電子紙與水墨三種顯示模式
- 可選語音播報、音效及 PWA 離線遊玩
- 桌面與手機自適應操作

## GitHub Pages 部署

1. 解壓縮 ZIP。
2. 將 `index.html`、`game.js`、`styles.css`、`manifest.webmanifest`、`service-worker.js`、`README.md`、`TEST_REPORT.md` 及 `assets` 資料夾直接上傳到 GitHub 儲存庫根目錄。
3. 到 GitHub 儲存庫的 **Settings → Pages**，選擇從主要分支根目錄發布。
4. 部署完成後按 `Ctrl + F5` 強制重新整理。

不要只上傳外層 `water-margin-rpg-v3.4.0` 資料夾，否則 GitHub Pages 可能找不到首頁。

## PWA 更新

Service Worker 快取名稱為 `liangshan-rpg-v3.4.0`。覆蓋新版檔案後請強制重新整理；若已安裝為 PWA，請完全關閉後重新開啟，以載入新版快取。

## 舊存檔相容性

v3.4.0 會自動補齊侯健、湯隆、第二十三回任務、百工安作院、安作線索及軍略欄位。舊版英雄、裝備、同伴、建築與章回進度均會保留。
