# 水滸英雄傳：梁山風雲 v2.3.0

以《水滸傳》重要章回改編的單機網頁 RPG。遊戲可直接在瀏覽器執行，支援電腦與手機、離線安裝、本機存檔、語音播報、水墨／深色／黑白電子紙顯示模式。

## v2.3.0「受詔招安・雁門征遼」

本版新增第十二回：朝廷回覆梁山三約後，眾英雄受詔北上雁門。玩家須監督軍糧、保護邊民、校準北風騎射，再以五階段「雁門鎖關」軍略擊破遼軍鷹狼陣。

### 新增內容

- 新增第十二名主角「小李廣花榮」
- 新增花榮技能「穿雲箭」「燕尾連珠」
- 新增同伴「大刀關勝」及援護「青龍偃月斬」
- 新增受詔三約與北征軍糧選擇
- 新增風向、弓弦與箭羽騎射校準
- 新增五階段雁門鎖關軍略
- 新增遼軍鷹騎斥候與南院先鋒首領戰
- 新增梁山建築「馬廄」
- 新增雁門騎射場與可重演軍略
- 英雄譜擴充為十二名可操作主角
- 保留語音播報、山寨建設、遠征與水陸軍略
- 相容 v1.0～v2.2.0 舊存檔

## 執行方式

### 直接開啟

解壓縮後開啟 `index.html` 即可遊玩。部分瀏覽器對本機檔案的 PWA 與語音權限有限，正式使用建議部署到 HTTPS 網站。

### GitHub Pages

將壓縮檔內下列內容直接放在儲存庫最上層：

```text
index.html
styles.css
game.js
manifest.webmanifest
service-worker.js
README.md
TEST_REPORT.md
assets/
```

不要只上傳外層 `water-margin-rpg-v2.3.0` 資料夾，否則 GitHub Pages 可能找不到首頁。

## 存檔

遊戲使用瀏覽器 LocalStorage，存檔鍵為：

```text
liangshan-rpg-save-v1
```

更新版本時不要清除網站資料，即可保留進度。v2.2.0 存檔載入後會自動新增花榮、關勝、第十二回、雁門軍略與馬廄資料。

## 主要檔案

- `index.html`：頁面結構與遊戲模板
- `styles.css`：桌面、手機及三種顯示模式
- `game.js`：劇情、戰鬥、存檔、語音及建設系統
- `manifest.webmanifest`：PWA 資訊
- `service-worker.js`：離線快取
- `TEST_REPORT.md`：本版測試紀錄
