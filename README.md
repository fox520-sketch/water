章回式單機網頁 RPG，以 HTML、CSS 與 JavaScript 製作，可直接部署到 GitHub Pages，也支援 PWA 安裝與離線遊玩。

本版新增：

- 第十五回完整主線「征方臘・湧金門夜襲」
- 第十五名可操作英雄「浪裡白條張順」
- 張順專屬技能「浪裡分波」「水遁奪門」

- 五階段「湧金門夜襲」水戰軍略
- 新同伴「活閻羅阮小七」與水下斷纜援護
- 方臘江防斥候、水柵親軍與方天定首領戰
- 「原著悲壯／協同救援」可改寫分歧
- 新建築「梁山水門工坊」

- 十五英雄自由切換
- v1.0～v2.5.0 舊存檔相容

## 湧金門夜襲正確順序

1. 張順核定退潮與暗流時刻
2. 阮小七潛拆水柵暗樁
3. 戴宗換送假水燈調開巡船
4. 花榮射熄城樓火箭號燈
5. 張順開湧金門護送船戶

錯誤順序會消耗水軍軍勢並提高水門警戒。潮汐線索、江南軍紀、船塢及水門工坊等級，都會實際改變軍略難度。

## 張順命運分歧

完成至少三項潮汐線索、將水門工坊升至 Lv.2，或維持足夠的江南軍紀，可讓阮小七及時接應張順，改寫原著湧金門悲劇。

準備不足時，遊戲仍可閱讀原著悲壯線，再退回軍議重新偵察與調整救援，不會強迫永久失去可操作英雄。

## 執行方式

直接開啟 `index.html` 即可遊玩。PWA 安裝與離線快取建議透過 HTTPS 或本機 HTTP 伺服器執行。

## GitHub Pages 部署

請把下列內容直接放在 repository 根目錄：

```text
index.html
styles.css
game.js
manifest.webmanifest
service-worker.js
README.md
TEST_REPORT.md
assets/
```

不要只上傳外層 `water-margin-rpg-v2.6.0` 資料夾，否則 GitHub Pages 可能找不到首頁。

## 更新注意事項

Service Worker 快取名稱已更新為 `liangshan-rpg-v2.6.0`。覆蓋新版後，請使用 `Ctrl + F5` 強制重新整理；已安裝成 PWA 時，請完全關閉後重新開啟。

## 存檔

遊戲沿用既有存檔鍵：

```text
liangshan-rpg-save-v1
```

載入舊存檔時會自動補入張順、阮小七、第十五回任務、潮汐線索、水戰軍略及水門工坊，不會清除既有英雄、裝備、羈絆、建築與章回進度。
