# 水滸英雄傳：梁山風雲 v3.8.0

章回式單機網頁 RPG，以《水滸傳》人物與事件為基礎進行互動式改編。本版延續 v3.7.0 的水泊人畜安康制度，新增第二十七回「操刀驗膳與百膳安民」。

## v3.8.0「第二十七回・操刀驗膳與百膳安民」

- 新增第二十七名主角「操刀鬼・曹正」
- 新增曹正技能「操刀驗源」與「四案分膳」
- 新增同伴「母夜叉・孫二娘」及援護技能「母夜叉護灶」
- 新增食材來源、淨水熟度、生熟分案、每餐留樣四項膳安線索
- 新增五階段「水泊百膳安民」軍略
- 新增摻假食材巡丁、黑廚牙行護院、膳利掮客與黑廚豪商等敵人
- 新增「梁山膳安公驗院」及四處輿圖地點
- 新增「水泊膳安失序／公開百膳安民」分歧劇情
- 新增三項章回收藏及百膳安民演武場
- 二十七位英雄可於完成各自章回後自由切換

## 本版修正

- 修正侯健、湯隆、凌振、皇甫端與曹正從英雄譜切換時，章回編號及返回據點可能錯誤的問題
- 修正四項膳安線索全數查齊後，五階段軍略最後一步仍可能被鎖住的數值門檻
- 更新首頁、遊戲指南、版本介紹、聚義座次、總成果、Manifest 與 PWA 離線快取

## 遊戲特色

- 二十七回完整主線與二十七名可操作英雄
- 回合制戰鬥、角色專屬技能及同伴援護
- 調查線索、軍略推演、分歧劇情及重複演武
- 梁山建設、英雄譜、江湖輿圖、快速整備及本機存檔
- 水墨宣紙、深色及黑白電子紙三種顯示模式
- 可選語音播報與 PWA 離線遊玩
- 純 HTML、CSS、JavaScript，不需要資料庫或後端伺服器

## GitHub Pages 部署

1. 解壓縮 ZIP。
2. 將 `index.html`、`game.js`、`styles.css`、`manifest.webmanifest`、`service-worker.js`、說明文件及 `assets` 資料夾直接上傳至儲存庫根目錄。
3. 不要只上傳外層 `water-margin-rpg-v3.8.0` 資料夾，否則 GitHub Pages 可能找不到首頁。
4. 發布後按 `Ctrl + F5` 強制重新整理。

## PWA 快取

Service Worker 快取名稱為 `liangshan-rpg-v3.8.0`。覆蓋新版檔案後請強制重新整理；若已安裝為 PWA，請完全關閉後重新開啟，以載入新版快取。

## 舊存檔升級

v3.8.0 會自動補齊曹正、孫二娘、第二十七回任務、膳安公驗院、膳安線索及百膳軍略欄位。舊版英雄、裝備、同伴、建築與章回進度均會保留。

存檔使用瀏覽器 LocalStorage；清除網站資料或更換瀏覽器、裝置，不會自動同步原有進度。
