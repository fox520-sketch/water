# 水滸英雄傳：梁山風雲 v2.8.0

章回式單機網頁 RPG，以 HTML、CSS 與 JavaScript 製作，可直接部署到 GitHub Pages，並支援 PWA、離線快取、語音播報與瀏覽器本機存檔。

## v2.8.0「第十七回・東京功冊與忠義封賞」

本版新增：

- 第十七回完整主線「東京功冊・忠義封賞」
- 第十七名可操作英雄「神機軍師朱武」
- 朱武專屬技能「神機陣盤」「四門鎖陣」
- 班師點名冊、軍民撫卹簿、勅書印樣與封賞交割四項功冊線索
- 五階段「東京忠義護冊」軍略
- 新同伴「鐵面孔目裴宣」與「鐵面勘驗」援護
- 截冊禁軍、功冊司親隨、高俅餘黨與密詔使首領戰
- 「功名散失／公開保全」可改寫分歧
- 新建築「忠義文案閣」
- 東京神機護冊演武場
- 手機版江湖輿圖改為雙欄地點清單，避免章回增加後節點重疊
- 十七英雄自由切換
- v1.0～v2.7.0 舊存檔相容

## 東京忠義護冊正確順序

1. 戴宗分送三份功冊副本
2. 蕭讓校對勅書紙印副署
3. 裴宣核驗傷亡與撫卹交割
4. 朱武布四門護冊陣
5. 宋江公開封賞與離隊名錄

前四步尚未完成，或抽冊封鎖尚未削弱到指定程度時，最後的公開封賞會維持鎖定。

## 朱武專屬技能

### 神機陣盤

造成傷害、削弱敵方筋骨、恢復少量豪氣，並提高下一次普通攻擊重創機率。

### 四門鎖陣

造成強力傷害、削弱敵方武力、建立守勢與兩回合防護，並有機會封住敵方號令一回合。

## 執行方式

直接開啟 `index.html` 即可遊玩。PWA 安裝與離線快取建議透過 HTTPS 或本機 HTTP 伺服器執行。

## GitHub Pages 部署

請把下列內容直接放在 repository 根目錄：

```text
index.html
styles.css
game.js
manifest.webmanifest
service-worker.js
README.md
TEST_REPORT.md
assets/
```

不要只上傳外層 `water-margin-rpg-v2.8.0` 資料夾。

## 更新注意事項

Service Worker 快取名稱已更新為 `liangshan-rpg-v2.8.0`。覆蓋新版後請按 `Ctrl + F5` 強制重新整理；已安裝成 PWA 時，請完全關閉後重新開啟。

## 存檔

遊戲沿用既有存檔鍵：

```text
liangshan-rpg-save-v1
```

載入舊存檔時會自動補入朱武、裴宣、第十七回任務、功冊線索、東京護冊軍略與忠義文案閣，不會清除既有英雄、裝備、羈絆、建築、資源與前十六回進度。
