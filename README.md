# 水滸英雄傳：梁山風雲 v1.9.0

純 HTML、CSS、JavaScript 製作的單機章回式網頁 RPG，可直接部署到 GitHub Pages。

## v1.9.0 新增

- 第八回「大破連環馬」完整主線
- 新主角「雙鞭將呼延灼」與八英雄自由切換
- 呼延灼專屬技能：雙鞭鎮嶽、連環馬令
- 官軍／梁山雙視角敘事
- 新同伴「金槍手徐寧」與鉤鐮破騎援護
- 五階段「鉤鐮槍破連環馬」陣型戰
- 連環馬軍紀、養馬與鉤鐮槍訓練數值
- 新建築「軍械坊」
- 山寨遠征：濟州糧道、青州馬場、滄州鐵礦
- 鉤鐮槍演武與軍械建材獎勵
- v1.0～v1.8 舊存檔自動升級

## 執行方式

直接開啟 `index.html` 即可。PWA、離線快取與安裝功能需透過 HTTPS 或 localhost 執行。

## GitHub Pages

請將 `index.html`、`styles.css`、`game.js`、`manifest.webmanifest`、`service-worker.js`、`assets/` 直接放在儲存庫根目錄。
