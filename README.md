# 水滸英雄傳：梁山風雲 v4.8.0

章回式單機網頁 RPG。本版延續 v4.7.0 的百道安行制度，新增第三十七回「摸著天量屋・百居安住」，讓梁山公共治理由道路橋涵延伸至宅基地界、房屋結構、防火疏散、租修公示、危屋支撐與臨時安置。

## v4.8.0 新增內容

- 第三十七名主角「摸著天・杜遷」
- 新同伴「雲裡金剛・宋萬」及援護技能「雲裡金剛托梁」
- 杜遷專屬技能「摸著天量屋」與「四院安住」
- 第三十七回完整主線：侵占宅基、危屋偷工、堵塞火巷、黑租逼遷及災後拒絕安置
- 四項住居查驗：宅基地界、地基梁柱、防火疏散、房牌租修與危屋安置
- 五階段軍略：宅基分界、結構驗固、防火疏散、租修公示、危屋安置
- 三場主線戰鬥、百居安住演武與住居軍略重演
- 新地點：金沙灘宅基梁柱踏勘場、梁山百居安住署、水泊安心居住里、百居安住演武場
- 新裝備與制度物品：摸著天量屋桿、百居安住甲、住居安全總冊、修繕安置簿、百居安住約
- 新增百居安住署建設與三十七英雄譜、聚義座次及總成果

## 存檔相容

- 支援 v1.0.0～v4.7.0 舊存檔自動升級
- 舊存檔會自動補入杜遷英雄資料、宋萬同伴資料、專屬裝備、第三十七回任務、旗標、戰鬥狀態與百居安住署
- v4.7.0 已完成第三十六回的存檔，可直接從章回結尾或百道安行演武場開啟第三十七回

## 執行方式

直接開啟 `index.html` 即可遊玩。部署至 GitHub Pages 等 HTTPS 網站後，可安裝為 PWA 並支援離線快取。

Service Worker 快取名稱：`liangshan-rpg-v4.8.0`。

## 檔案

- `index.html`：頁面結構與遊戲模板
- `styles.css`：桌面、手機、深色與黑白電子紙模式
- `game.js`：角色、章回、戰鬥、軍略、存檔與介面邏輯
- `manifest.webmanifest`：PWA 資訊
- `service-worker.js`：離線快取
- `assets/`：PWA 圖示
- `TEST_REPORT.md`：本版測試結果
