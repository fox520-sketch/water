# 水滸英雄傳：梁山風雲 v3.9.0

章回式單機網頁 RPG，以《水滸傳》人物與事件為基礎進行互動式改編。本版延續 v3.8.0 的水泊百膳安民制度，新增第二十八回「母夜叉護驛與百宿安行」。

## v3.9.0「第二十八回・母夜叉護驛與百宿安行」

- 新增第二十八名主角「母夜叉・孫二娘」
- 新增孫二娘技能「母夜叉驗宿」與「四更護驛」
- 新增同伴「菜園子・張青」及援護技能「菜園子接驛」
- 新增旅客身份、酒食樣本、行李封籤、夜巡求援四項宿安線索
- 新增五階段「水泊百宿安行」軍略
- 新增迷藥黑棧巡丁、黑棧牙行護院、宿利掮客與黑棧豪商等敵人
- 新增「梁山宿安巡驗館」及四處輿圖地點
- 新增「水泊宿安失序／公開百宿安行」分歧劇情
- 新增三項章回收藏及百宿安行演武場
- 二十八位英雄可於完成各自章回後自由切換

## 本版修正

- 補齊菜園子張青的同伴說明、羈絆與英雄譜進度顯示
- 統一首頁、版本介紹、遊戲指南、聚義座次、總成果與 PWA 快取為二十八章回
- 延續第 23～28 名英雄章回編號、返回據點與輿圖自動切換回歸檢查
- 更新宿安軍略最後階段門檻，完整調查四項線索後可正常完成公開救援與補償

## 遊戲特色

- 二十八回完整主線與二十八名可操作英雄
- 回合制戰鬥、角色專屬技能及同伴援護
- 調查線索、軍略推演、分歧劇情及重複演武
- 梁山建設、英雄譜、江湖輿圖、快速整備及本機存檔
- 水墨宣紙、深色及黑白電子紙三種顯示模式
- 可選語音播報與 PWA 離線遊玩
- 純 HTML、CSS、JavaScript，不需要資料庫或後端伺服器

## GitHub Pages 部署

1. 解壓縮 ZIP。
2. 將 `index.html`、`game.js`、`styles.css`、`manifest.webmanifest`、`service-worker.js`、說明文件及 `assets` 資料夾直接上傳至儲存庫根目錄。
3. 不要只上傳外層 `water-margin-rpg-v3.9.0` 資料夾，否則 GitHub Pages 可能找不到首頁。
4. 發布後按 `Ctrl + F5` 強制重新整理。

## PWA 快取

Service Worker 快取名稱為 `liangshan-rpg-v3.9.0`。覆蓋新版檔案後請強制重新整理；若已安裝為 PWA，請完全關閉後重新開啟，以載入新版快取。

## 舊存檔升級

v3.9.0 會自動補齊孫二娘主角、菜園子張青、第二十八回任務、宿安巡驗館、四項宿安線索及百宿軍略欄位。舊版英雄、裝備、同伴、建築與章回進度均會保留。

存檔使用瀏覽器 LocalStorage；清除網站資料或更換瀏覽器、裝置，不會自動同步原有進度。
