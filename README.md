# 水滸英雄傳：梁山風雲 v1.8.0

純 HTML、CSS、JavaScript 製作的單機章回式網頁 RPG，可直接放上 GitHub Pages。

## v1.8.0 新增

- 第七回「三打祝家莊」完整主線
- 第一打：盤陀路偵察、外寨槍隊與敗退護民選擇
- 第二打：切換扈三娘視角，使用日月雙刀與紅錦套索
- 第三打：李應封援、孫立臥底、花榮斷鐘與三路總攻
- 新增「祝家莊攻略」策略戰：莊寨防線、梁山攻勢、警報值
- 新主角「一丈青扈三娘」與七英雄自由切換
- 新同伴「病尉遲孫立」及登州破陣援護
- 新增三莊聯盟聲望與戰後護民／分糧抉擇
- 新增梁山糧草、糧倉建築與全寨整備
- 新增獨龍岡演武與糧草獎勵
- 完整保留 v1.0～v1.7 存檔相容、語音播報、PWA 與三種顯示模式

## 執行

直接開啟 `index.html` 即可遊玩。PWA 與離線快取需透過 HTTPS（例如 GitHub Pages）使用。

## GitHub Pages

將 `index.html`、`game.js`、`styles.css`、`manifest.webmanifest`、`service-worker.js`、`assets/` 等內容放在儲存庫最上層。

## 存檔

使用瀏覽器 LocalStorage，鍵名維持 `liangshan-rpg-save-v1`。清除網站資料會刪除存檔。
