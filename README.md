# 水滸英雄傳：梁山風雲 v3.6.0

章回式單機網頁 RPG，以《水滸傳》人物與事件為基礎進行互動式改編。本版延續 v3.5.0 的水泊百器公檢，新增第二十五回「轟天鳴警與水泊聯防」。

## v3.6.0「第二十五回・轟天鳴警與水泊聯防」

- 新增第二十五名可操作英雄「轟天雷・凌振」
- 新增凌振專屬技能「轟天辨號」與「四隅聯防」
- 新增同伴「紫髯伯・皇甫端」及援護技能「紫髯分診」
- 新增警號節律、火源分區、疏散路線、人畜救護四項線索
- 新增五階段「水泊四隅聯防」軍略
- 新增三場第二十五回主線戰鬥及四隅聯防演武
- 新增「梁山災防鳴警臺」與四處輿圖地點
- 新增警號總冊、疏散救護簿及聯防新約三項收藏
- 新增聯防失序與公開災防分歧路線
- 二十五位英雄自由切換
- 完整保留 v1.0～v3.5.0 舊存檔

## 同步修正

- 旅行至第二十四、二十五回地點時可自動開啟或切換正確主角
- 章回成果、聚義座次、梁山建設與演武統計更新為二十五英雄
- 江湖輿圖改為桌面四欄、平板三欄、手機雙欄卡片排列，避免地點重疊
- 更新首頁、遊戲指南、版本說明、Manifest 與 PWA 離線快取

## 執行方式

直接開啟 `index.html` 即可遊玩。為確保 PWA、語音與離線快取正常，建議透過 GitHub Pages 或本機 HTTP 伺服器執行。

## GitHub Pages 部署

1. 解壓縮 ZIP。
2. 將 `index.html`、`game.js`、`styles.css`、`manifest.webmanifest`、`service-worker.js`、說明文件及 `assets` 資料夾直接上傳至儲存庫根目錄。
3. 不要只上傳外層 `water-margin-rpg-v3.6.0` 資料夾，否則 GitHub Pages 可能找不到首頁。
4. 部署後按 `Ctrl + F5` 強制重新整理。

## PWA 快取

Service Worker 快取名稱為 `liangshan-rpg-v3.6.0`。覆蓋新版檔案後請強制重新整理；若已安裝為 PWA，請完全關閉後重新開啟，以載入新版快取。

## 舊存檔升級

v3.6.0 會自動補齊凌振、皇甫端、第二十五回任務、災防鳴警臺、聯防線索及軍略欄位。舊版英雄、裝備、同伴、建築與章回進度均會保留。
