# 水滸英雄傳：梁山風雲 v1.5.0

以《水滸傳》重要章回改編的單機網頁 RPG。本版新增第四回「智取生辰綱」，透過楊志押送與吳用設局的交錯視角，將護送戰鬥、隊伍軍紀與黃泥岡智策對決整合為完整章回。

## v1.5.0 新增內容

- 第四回完整主線：大名府點將、秘密押綱、酷暑行軍、黃泥岡遇賊、七星聚義、白勝賣酒、蒙汗藥智局與楊志失綱
- 新主角「青面獸・楊志」
- 楊志專屬技能「青面斬」「護綱軍令」
- 新增護送隊「軍紀／士氣」數值，前段決策會影響戰鬥與智策難度
- 新增「黃泥岡智策對決」，以觀天、賣酒、佯爭、偷瓢及下藥完成計策連鎖
- 新同伴「智多星・吳用」，援護技能可削弱敵人並恢復豪氣
- 新敵人：黃泥岡剪徑賊、追捕官兵、大名府刀牌教頭
- 新地點：大名府、濟州山路、黃泥岡
- 新裝備與信物：楊家雁翎刀、護綱札甲、生辰綱封記、棗瓢暗記
- 黃泥岡智策關卡與大名府演武據點可重複挑戰
- 英雄譜擴充為武松、魯智深、林沖、楊志四主角
- 章回成果、任務簿、江湖輿圖及語音播報同步擴充
- 保留音效、深色模式、電子紙模式、PWA 與本機存檔

## 開啟方式

直接開啟 `index.html` 即可遊玩。若需要完整 PWA 安裝與離線快取，請部署到 GitHub Pages 等 HTTPS 網站。

## GitHub Pages

請將以下內容直接放在儲存庫根目錄：

- `index.html`
- `styles.css`
- `game.js`
- `manifest.webmanifest`
- `service-worker.js`
- `assets/`
- `README.md`
- `TEST_REPORT.md`

不要只上傳外層的 `water-margin-rpg-v1.5.0` 資料夾，否則 GitHub Pages 可能找不到首頁。

## 存檔與舊版升級

遊戲使用瀏覽器 LocalStorage，存檔鍵沿用 `liangshan-rpg-save-v1`。

v1.0～v1.4 存檔讀取時會自動：

- 保留既有英雄、裝備、行囊、任務及同伴羈絆
- 補入楊志、吳用與第四回資料
- 升級為四主角存檔結構
- 將升級後格式立即寫回本機存檔

首次更新後建議重新整理一次頁面；若使用已安裝的 PWA，可完全關閉後再重新開啟，以取得新版快取。
