# 水滸英雄傳：梁山風雲 v7.4.0

## 梁山遠征與雲端傳承版

一款可離線遊玩的繁體中文網頁 RPG，包含 108 回主線、英雄養成、速度回合戰鬥、梁山寨建設與主線後長期挑戰。

## v7.4.0 主要內容

- 36 天罡英雄各自擁有手工設計的主動技、被動與特殊機制。
- 戰術 AI 可設定猛攻、穩健、控場、首領戰等策略，以及目標優先、用藥門檻與保留覺醒技。
- 每回加入 12 類輪替的判斷關卡，成功或失誤會改變敵情、獎勵、評分及分支結局。
- 新增無盡塔、六路遠征與已完成章回的首領再戰。
- 裝備擴充為武器、防具、頭盔、鞋履、護符、坐騎六部位。
- 新增副屬性重鑄、裝備鎖定、二件／四件套效果，以及每部位第十次鍛造傳說保底。
- 梁山寨可累積生產銀兩與素材，並派遣英雄執行五類任務。
- Firebase 雲端存檔為選用功能；未設定時仍可完全離線遊玩。
- 存檔採 IndexedDB 主存檔、localStorage 相容鏡像、Schema 驗證、校驗碼與十份輪替備份。
- 支援鍵盤快捷鍵、焦點鎖定、高對比、文字縮放、減少動畫及螢幕閱讀器標籤。
- 天罡、存檔、雲端、長期玩法、章回內容與無障礙已拆為獨立模組。

## 開始遊戲

### Windows ZIP

1. 解壓縮 `Liangshan_v7.4.0_Windows.zip`。
2. 進入 `Liangshan_v7.4.0`。
3. 雙擊 `index.html`。

### 單一 HTML

直接開啟 `Liangshan_v7.4.0_Standalone.html`，不需要解壓縮其他資源。

單一 HTML 可遊玩與保存本機進度，但 Service Worker、PWA 安裝及 Firebase 跨裝置同步建議部署到 HTTPS 網站後使用。

## 舊存檔

可承接 v7.0.0～v7.3.0 的章回、英雄、編隊、裝備、建設、銀兩及設定。舊戰鬥格式若正在進行，升級時會安全退回戰前。

## Firebase

請參閱 `FIREBASE_SETUP.md`。雲端同步不會自動覆蓋本機；下載後會先顯示本機與雲端比較，並在套用前建立備份。

## GitHub Pages

請參閱 `DEPLOY_GITHUB_PAGES.md`。專案已包含 Pages 與 Release 的 GitHub Actions 工作流程。

## 重要限制

- 公開 GitHub Pages 網址尚未由本環境直接發布，因為沒有使用者儲存庫的寫入權限。
- Firebase 真實跨裝置驗收需要使用者自己的 Firebase 專案設定。
- 專案已完成發布前的相對路徑、Service Worker 資產、離線清單與模擬 REST 驗證；公開 HTTPS 的最後驗收仍須部署後執行。
