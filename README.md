# 水滸英雄傳：梁山風雲 v4.4.0

章回式單機網頁 RPG。本版延續 v4.3.0 的水泊百林共護制度，新增第三十三回「雙尾蠍辨藥・百藥安採」，完成三十三英雄與公共藥材安採、封存及召回系統。

## v4.4.0 新增內容

- 第三十三名主角「雙尾蠍・解寶」
- 專屬技能「雙尾蠍辨藥」「四谷安採」
- 新同伴「出林龍・鄒淵」及援護「出林龍護採」
- 四項百藥線索：藥材辨種與產地採期、分區輪採與留根復育、洗切乾燥與含水防霉、批次追溯與藥害召回補償
- 三場主線戰鬥及五階段「水泊百藥安採」軍略
- 新建築「梁山百藥安採署」
- 四處新地點：藥材辨種場、百藥安採署、安心藥材市、百藥安採演武場
- 三項收藏：水泊藥材辨種總冊、乾燥封存與召回補償簿、水泊百藥安採約
- 支援 v1.0～v4.3.0 舊存檔自動升級

## 同步修正

- 補齊解寶英雄建立、專屬裝備、鄒淵同伴與百藥軍略狀態
- 舊存檔可自動新增第三十三名英雄、百藥安採署與第三十三回旗標
- 英雄譜補上解寶名稱、據點、解鎖提示、章回完成判定與切換說明
- 更新遊戲指南、版本介紹、三十三英雄與三十三名同伴說明
- 更新首頁、Manifest 與 PWA 離線快取

## 部署

解壓縮後，將 `index.html`、`game.js`、`styles.css`、`manifest.webmanifest`、`service-worker.js`、`assets` 與其餘文件直接上傳至 GitHub Pages 儲存庫根目錄。更新後請按 `Ctrl + F5` 強制重新整理。

Service Worker 快取名稱：`liangshan-rpg-v4.4.0`。
