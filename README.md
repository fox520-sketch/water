# 水滸英雄傳：梁山風雲 v3.1.0

章回式單機網頁 RPG，以 HTML、CSS 與 JavaScript 製作，可直接部署到 GitHub Pages，支援 PWA、離線快取、語音播報、三種顯示模式與瀏覽器本機存檔。

## v3.1.0「第二十回・鐵叫傳信與百業共治」

本版新增：

- 第二十回完整主線「鐵叫傳信・百業共治」
- 第二十名可操作英雄「鐵叫子・樂和」
- 樂和專屬技能「鐵叫破謠」「百戶傳唱」
- 市價簿、工役輪值、真榜印樣與代表名冊四項百業線索
- 五階段「梁山百業共治」軍略
- 新同伴「玉臂匠・金大堅」與「玉臂刻印」援護
- 偽榜煽眾客、壟斷牙行護院、黑榜牙行與壟斷豪商三場主線戰鬥
- 「百業失衡／日常共治」可改寫分歧
- 新建築「梁山百業公示院」
- 百業共治演武場
- 二十英雄自由切換
- 補上第十九回公議線索與止鬥紀律的實際戰鬥減益
- v1.0～v3.0.0 舊存檔相容

## 梁山百業共治正確順序

1. 樂和公開真榜與更正來源
2. 金大堅同刻印樣並分路留存
3. 蔣敬公布市價、工價與牙行抽成
4. 裴宣核驗工役與代表輪值
5. 宋江建立代表更正與撤換制度

前四步尚未完成，或偽榜壟斷封鎖尚未削弱到指定程度時，最後的代表更正與撤換會維持鎖定。

## 樂和專屬技能

### 鐵叫破謠

造成傷害、同時削弱敵方武力與筋骨，恢復部分豪氣並提高下一次普通攻擊的重創機率。百業線索越完整，削弱效果越強。

### 百戶傳唱

造成強力傷害、削弱敵方武力並建立兩次防護；有機會讓偽榜號令暫停一回合。百業公示院等級越高，威力越強。

## 執行方式

直接開啟 `index.html` 即可遊玩。PWA 安裝與離線快取建議透過 HTTPS 或本機 HTTP 伺服器執行。

## GitHub Pages 部署

請把下列內容直接放在 repository 根目錄：

```text
index.html
styles.css
game.js
manifest.webmanifest
service-worker.js
README.md
TEST_REPORT.md
assets/
```

不要只上傳外層 `water-margin-rpg-v3.1.0` 資料夾。

## 更新注意事項

Service Worker 快取名稱已更新為 `liangshan-rpg-v3.1.0`。覆蓋新版後請按 `Ctrl + F5` 強制重新整理；已安裝成 PWA 時，請完全關閉後重新開啟。

## 存檔

遊戲沿用既有存檔鍵：

```text
liangshan-rpg-save-v1
```

載入舊存檔時會自動補入樂和主角、金大堅同伴、第二十回任務、百業線索、梁山百業共治、百業公示院與相關旗標，不會清除既有英雄、裝備、羈絆、建築、資源及前十九回進度。
