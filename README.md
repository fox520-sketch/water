# 水滸英雄傳：梁山風雲 v7.2.0

## 梁山聚義養成版

這是一款可直接在瀏覽器執行的繁體中文網頁 RPG，保留第一回至第一百零八回完整章回，並加入隊伍、英雄、裝備與梁山寨養成系統。

## v7.2.0 核心內容

### 自由編隊與前後排

- 四人隊伍：前排 2 名、後排 2 名。
- 前排較容易成為攻擊目標，但具有減傷。
- 後排傷害提高，但會被術士型敵人優先針對。
- 已解鎖英雄可自由互換，同一英雄不會重複上陣。

### 英雄等級、技能樹與專屬被動

- 108 名英雄各自保存等級、經驗與出戰紀錄。
- 升級可取得技能點。
- 武勇、守備、謀略三條技能樹，各可升至 3 級。
- 每名英雄都有依綽號與定位產生的唯一專屬被動名稱。

### 人物羈絆與合擊技

已加入步戰雙雄、梁山軍略、揭陽水師、阮氏三雄、登州獵戶、揭陽兄弟、青州雙傑、飛天雙煞、神箭雙星等羈絆。

戰鬥中累積合擊值至 100 後，可施展全體攻擊、護盾、治療、暈眩、燃燒、流血或破甲等效果。

### 多敵人、狀態與首領階段

- 前哨戰：四名英雄對兩名敵人。
- 查驗戰：四名英雄對三名敵人。
- 首領戰：首領與兩名以上親兵共同出戰。
- 可點選敵方卡片指定攻擊目標。
- 支援中毒、燃燒、流血、暈眩、破甲、護盾、嘲諷與鼓舞。
- 首領在氣血 70% 與 35% 時進入第二、第三階段。
- 六種首領機制：鐵甲、暴怒、回生、援兵、毒霧、反震。

### 武器、防具、鍛造與分解

- 鍛造武器與防具，可能取得凡品、精良或傳說品質。
- 裝備可強化至 +5。
- 英雄可一鍵裝備目前最佳武器與防具。
- 未裝備物品可分解為鐵礦、布料與精華。

### 梁山寨建設

六棟建築皆可升至 5 級：

- 聚義廳：提高生命與章回經驗。
- 軍械庫：提高裝備與鍛造品質。
- 醫館：提高藥品治療並降低補給價格。
- 馬廄：提高豪氣與自動戰鬥效率。
- 水寨：提高水軍與後排傷害。
- 情報所：提高暴擊並顯示首領階段。

### 戰鬥速度與自動戰鬥

- 可選擇 ×1、×2、×3 速度。
- 自動戰鬥會依血量、豪氣、敵人數量與合擊值選擇行動。
- 可隨時切回手動操作。

## 舊存檔升級

v7.1.0 使用相同的 v7 存檔鍵。第一次開啟 v7.2.0 時會：

- 保留銀兩、108 回完成紀錄、多章回暫存與最近遊玩。
- 保留難度、主題與其他偏好。
- 新增英雄、編隊、裝備、材料與梁山建設欄位。
- 若舊版停在戰鬥中，會安全回到該章回的戰前狀態。
- 升級前會建立舊版存檔備份。

## Windows 使用方式

1. 對 `Liangshan_v7.2.0_Windows.zip` 按滑鼠右鍵。
2. 選擇「全部解壓縮」。
3. 開啟 `Liangshan_v7.2.0` 資料夾。
4. 雙擊 `index.html`。

壓縮檔內所有路徑與檔名皆使用英文 ASCII 字元，降低 Windows 內建解壓縮的相容性問題。

## PWA 說明

直接雙擊 `index.html` 可正常遊玩與存檔，但 PWA 安裝、離線快取與版本更新提示需要部署在 HTTPS 網站或 localhost，例如 GitHub Pages。

## 單一 HTML 版

`Liangshan_v7.2.0_Standalone.html` 已把 CSS、章回資料及程式整合在單一檔案中，不需解壓縮。單檔版不包含 PWA 安裝與離線更新功能。
