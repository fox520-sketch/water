# 水滸英雄傳：梁山風雲 v4.7.0

章回式單機網頁 RPG。本版延續 v4.6.0 的百田安灌制度，新增第三十六回「九尾龜築路・百道安行」，讓梁山公共治理由農田灌排延伸至道路、橋涵、護坡、路況公示與災時搶通救援。

## v4.7.0 新增內容

- 第三十六名主角「九尾龜・陶宗旺」
- 新同伴「摸著天・杜遷」與援護技能「摸著天架橋」
- 陶宗旺雙技能：「九尾龜築路」與「四路安行」
- 第三十六回完整主線：封道勒索、危橋偷工、排水坍方、暗夜無標、冒名收費與災時阻救
- 四項查驗：道路路線、橋涵基礎、排水護坡、路況收費與救援
- 五階段軍略：「路線分界、橋涵驗固、排水護坡、標誌公示、養護救援」
- 三場主線戰鬥與「百道安行演武場」重複挑戰
- 四個新地點：道路橋涵踏勘場、百道安行署、安心通行關、百道安行演武場
- 新裝備與制度物品：九尾龜築路鐵鍬、百道安行衣、道路橋涵巡檢總冊、橋涵護坡與養護救援簿、百道安行約
- 梁山建設新增「百道安行署」，可強化新章回軍勢與演練
- 三十六英雄譜、三十六名同伴資料、章回總結、遊戲指南與版本說明同步更新

## 相容性與存檔

- 支援 v1.0.0～v4.6.0 舊存檔自動升級
- 舊存檔會自動補入陶宗旺英雄資料、杜遷同伴資料、專屬裝備、第三十六回任務、旗標與百道安行署
- v4.6.0 已完成第三十五回的存檔，可直接從章回結尾或百田安灌演武場開啟第三十六回
- 存檔仍保存在目前瀏覽器的 `localStorage`；更換瀏覽器、裝置或清除網站資料前請先匯出存檔

## 執行方式

直接開啟 `index.html` 即可遊玩。若要啟用完整 PWA、離線快取及安裝功能，建議放在 GitHub Pages 或其他 HTTPS 靜態網站。

Service Worker 快取名稱：`liangshan-rpg-v4.7.0`。

## 主要檔案

- `index.html`：頁面、模板與 PWA 中繼資料
- `styles.css`：桌面、手機、深色與黑白電子紙顯示樣式
- `game.js`：角色、章回、戰鬥、軍略、存檔遷移與介面邏輯
- `manifest.webmanifest`：PWA 資訊
- `service-worker.js`：離線快取與更新
- `TEST_REPORT.md`：本版測試結果
