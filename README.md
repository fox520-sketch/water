# 水滸英雄傳：梁山風雲 v4.9.0

章回式單機網頁 RPG。本版延續 v4.8.0 的百居安住制度，新增第三十八回「雲裡金剛巡坊・百鄰安守」，讓梁山公共治理由安全住居延伸至坊里分區、門牌點戶、夜巡照明、求援通報、失聯搜尋與臨時避難。

## v4.9.0 新增內容

- 第三十八名主角「雲裡金剛・宋萬」
- 宋萬雙技能：「雲裡金剛巡坊」、「四坊安守」
- 新同伴「旱地忽律・朱貴」與「旱地忽律探訊」援護
- 第三十八回完整主線：假門牌藏匿、冒名巡夜、暗巷劫掠、求援受阻及災時失聯
- 四項鄰里查驗與五階段「水泊百鄰安守」軍略
- 三場主線戰鬥及百鄰安守演武
- 新增百鄰安守署、安心鄰里坊、坊里夜巡踏勘場及百鄰安守演武場
- 新增專屬武器、防具、坊里點戶總冊、求援避難簿及百鄰安守約
- 三十八英雄譜、聚義座次、總成果、PWA 描述及版本資訊同步更新

## 存檔相容

- 支援 v1.0.0～v4.8.0 舊存檔自動升級
- 舊存檔會自動補入宋萬英雄資料、朱貴同伴資料、專屬裝備、第三十八回任務、旗標、戰鬥狀態與百鄰安守署
- v4.8.0 已完成第三十七回的存檔，可直接從章回結尾或百居安住演武場開啟第三十八回

## 使用方式

直接開啟 `index.html` 即可遊玩。若部署至 GitHub Pages，請將本壓縮檔內所有檔案上傳至同一儲存庫目錄。

Service Worker 快取名稱：`liangshan-rpg-v4.9.0`。
