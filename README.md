# 水滸英雄傳：梁山風雲 v5.0.0

章回式單機網頁 RPG。本版延續 v4.9.0 的百鄰安守制度，新增第三十九回「旱地忽律辨訊・百信安傳」，讓梁山公共治理由鄰里互助延伸至訊源登錄、印記核驗、分級傳遞、更正回報、失聯信使追查與災時備援。

## v5.0.0 新增內容

- 第三十九名主角「旱地忽律・朱貴」
- 朱貴雙技能：「旱地忽律辨訊」、「四驛安傳」
- 新同伴「笑面虎・朱富」與「笑面虎聯驛」援護
- 第三十九回完整主線：匿名謠訊、偽造印記、截斷信使、拖延更正及災時假警報
- 四項消息查驗與五階段「水泊百信安傳」軍略
- 三場主線戰鬥及百信安傳演武
- 新增百信安傳署、安心訊驛、消息驛站踏勘場及百信安傳演武場
- 新增專屬武器、防具、訊源印時總冊、更正備援簿及百信安傳約
- 三十九英雄譜、聚義座次、總成果、PWA 描述及版本資訊同步更新
- 大版本整理：章回資料、舊存檔遷移、英雄切換、建築面板與手機版流程一致性檢查
- 修正朱貴已切換但戰鬥技能列仍顯示武松技能的接線問題
- 新增首戰與次戰後的安傳署整補，避免正式數值下連戰資源不足

## 存檔相容

- 支援 v1.0.0～v4.9.0 舊存檔自動升級
- 舊存檔會自動補入朱貴英雄資料、朱富同伴資料、專屬裝備、第三十九回任務、旗標、戰鬥狀態與百信安傳署
- v4.9.0 已完成第三十八回的存檔，可直接從章回結尾或百鄰安守演武場開啟第三十九回

## 使用方式

直接開啟 `index.html` 即可遊玩。若部署至 GitHub Pages，請將本壓縮檔內所有檔案上傳至同一儲存庫目錄。

Service Worker 快取名稱：`liangshan-rpg-v5.0.0`。
