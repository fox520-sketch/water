# 水滸英雄傳：梁山風雲 v6.2.0

## 新增章回

第五十一回「混江龍巡渡・百渡安航」

- 第五十一名主角：混江龍・李俊
- 新同伴：出洞蛟・童威
- 主角技能：混江龍分浪、百渡安航
- 同伴援護：出洞蛟破纜
- 四項查驗：船籍與掌舵、船體與載重、渡票與收費、水情與救援
- 五階段軍略：船籍掛牌、載重畫線、渡票明價、風浪停航、水陸救援
- 三場主線戰鬥、章回結算、五十一英雄譜、第三十五至五十一回章回錄

## v6.2.0 新功能

- 救生纜、風向旗、公示印三種行舟裝備
- 裝備分別影響守勢回復、技能消耗與戰鬥銀兩獎勵
- 依行動數、戰敗、用藥與最終戰援護計算 S／A／B／C 章回評級
- 四項章回成就：明辨舟契、三戰連捷、無藥破浪、混江獨航
- 自動承接 v6.1.0 第五十回完成紀錄、成就數與部分銀兩
- 匯入 v6.1.0 JSON 時自動備份並升級

## 開啟方式

直接開啟根目錄 `index.html`。部署到 GitHub Pages 後可安裝為 PWA。

## 存檔與前版保留

- v6.2.0 續篇存檔：`liangshan-rpg-sequel-v6`
- v6.1.0 前回備份：`liangshan-rpg-sequel-v6.1-backup`
- v6.0.0 前回備份：`liangshan-rpg-sequel-v6.0-backup`
- 經典篇存檔：`liangshan-rpg-save-v1`，新版只讀不覆寫
- 可由遊戲內匯出／匯入 JSON
- `previous-v6.1.0/`：可獨立重遊第五十回
- `previous-v6.0.0/`：可獨立重遊第四十九回
- `legacy-v4.5.0/`：完整保留經典篇
