# 水滸英雄傳：梁山風雲 v5.3.0

章回式單機網頁 RPG。本版延續 v5.2.0 的百案安查制度，新增第四十二回「鬼臉兒核契・百契安信」，讓梁山公共治理由查案取證延伸至立契身分、條款明示、本人印押、交割留據、副本登錄與履約救濟。

## v5.3.0 新增內容

- 第四十二名主角「鬼臉兒・杜興」
- 新同伴「撲天雕・李應」及援護技能「撲天雕護契」
- 杜興雙技能：「鬼臉兒核契」、「四約安信」
- 第四十二回完整主線：冒名立契、隱藏條款、強迫畫押、重複抵押、交割無據與拒絕履約救濟
- 四項契據查驗：身分代理、條款價額、印押見證、交割履約
- 五階段百契安信軍略：身分見證、條款明示、印押交割、副本登錄、履約救濟
- 三場主線戰鬥與百契安信演武
- 新增百契安信署、安心立契所、契據帳簿踏勘場及百契安信演武場
- 新增杜興專屬武器、防具及三項章回成果道具
- 世界地圖補齊第三十六回至第四十二回的據點導航

## 存檔相容

- 支援 v1.0.0 至 v5.2.0 舊存檔自動升級
- 舊存檔會自動補入杜興英雄、李應同伴、專屬裝備、第四十二回任務、旗標、軍略狀態與百契安信署
- v5.2.0 已完成第四十一回的存檔，可直接從章回結尾或百案安查演武場開啟第四十二回

## 執行方式

直接開啟 `index.html`；若瀏覽器限制本機 Service Worker，可透過 GitHub Pages 或其他靜態網站伺服器部署。

Service Worker 快取名稱：`liangshan-rpg-v5.3.0`。
