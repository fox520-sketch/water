# 水滸英雄傳：梁山風雲 v5.4.0

單機章回式網頁 RPG，可直接以瀏覽器開啟 `index.html`，亦支援 PWA 安裝與離線快取。

## v5.4.0 新增

- 第四十三回「撲天雕清產・百產安籍」
- 第四十三名主角：撲天雕・李應
- 新同伴：美髯公・朱仝
- 李應雙技能「撲天雕清產」、「四產安籍」
- 朱仝援護「美髯公護產」
- 四項產籍查驗與五階段百產安籍軍略
- 三場主線戰鬥、百產安籍演武與四個新地圖據點
- 百產安籍署及專屬武器、防具、總冊、備援簿與盟約
- 支援 v1.0.0～v5.3.0 舊存檔自動升級

## 執行方式

1. 解壓縮全部檔案。
2. 雙擊 `index.html` 開始遊戲。
3. 部署到 GitHub Pages 時，將壓縮檔內所有檔案放在同一專案目錄。

## 主要檔案

- `index.html`：遊戲頁面
- `game.js`：角色、章回、戰鬥與存檔邏輯
- `styles.css`：桌面與手機版介面
- `manifest.webmanifest`、`service-worker.js`：PWA 與離線支援
- `assets/`：應用程式圖示
