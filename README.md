# 水滸英雄傳：梁山風雲 v7.9.2

## 資料驗證與回歸測試強化版

本版重點是防止章回資料格式錯誤再次造成 `undefined`、`[object Object]` 等顯示異常。

### 新增

- 108 回章回資料格式驗證器。
- 108 回判斷題顯示自動測試。
- 自動偵測目前畫面是否出現 `undefined` 或 `[object Object]`。
- `update.html` 加入資料格式檢查、快取清除與檢查報告匯出。
- 維護中心新增存檔安全檢查、章回連鎖結果頁與強化問題回報。
- 同時提供更新包、完整包、單一 HTML 版與 rollback 包。

### 使用建議

更新後先開啟 `update.html`，按「開始完整檢查」。若 108 回資料格式與判斷題顯示都通過，再回到 `index.html` 遊玩。
