# 水滸英雄傳：梁山風雲 v5.2.0

章回式單機網頁 RPG。本版延續 v5.1.0 的百訴安解制度，新增第四十一回「青眼虎勘案・百案安查」，讓梁山公共治理由申訴受理延伸至報案立號、現場保全、物證鑑別、人證排查、禁止刑求、拘押移送、覆核回告與錯案補救。

## v5.2.0 新增內容

- 第四十一名主角「青眼虎・李雲」
- 李雲雙技能：「青眼虎勘案」、「四查安案」
- 新同伴「鬼臉兒・杜興」與「鬼臉兒識偽」援護
- 第四十一回完整主線：漏報壓案、毀跡調包、串供刑逼、私放關說、逾期移送及錯案不救
- 四項案件查驗與五階段「水泊百案安查」軍略
- 三場主線戰鬥及百案安查演武
- 新增百案安查署、安心報案所、案情現場踏勘場及百案安查演武場
- 新增專屬武器、防具、報案物證總冊、人證移送覆核簿及百案安查約
- 四十一英雄譜、聚義座次、總成果、PWA 描述及版本資訊同步更新
- 補上 v5.1.0 中青眼虎李雲作為同伴時的「青眼虎護證」戰鬥援護
- 擴充近四回敵人的撤退返回與章間整補對應

## 存檔相容

- 支援 v1.0.0～v5.1.0 舊存檔自動升級
- 舊存檔會自動補入李雲英雄資料、杜興同伴資料、專屬裝備、第四十一回任務、旗標、戰鬥狀態與百案安查署
- v5.1.0 已完成第四十回的存檔，可直接從章回結尾或百訴安解演武場開啟第四十一回

## 使用方式

直接開啟 `index.html` 即可遊玩。若部署至 GitHub Pages，請將本壓縮檔內所有檔案上傳至同一儲存庫目錄。

Service Worker 快取名稱：`liangshan-rpg-v5.2.0`。
