# 水滸英雄傳：梁山風雲 v2.7.0

本版新增：

- 第十六回完整主線「睦州決戰・忠義歸途」
- 第十六名可操作英雄「神行太保戴宗」
- 戴宗專屬技能「神行甲馬」「飛符急救」
- 傷兵名冊、山路驛標、糧道車轍及退兵烽號四項急援線索
- 五階段「睦州忠義急援」軍略
- 新同伴「神醫安道全」及分診救護援護
- 方臘截驛騎、睦州山道親軍及方臘中軍首領戰
- 「原著傷亡錄／協同急援」可改寫分歧
- 新建築「梁山軍醫營」
- 睦州神行救護演武場
- 十六英雄自由切換
- 全遊戲共用的「快速整備」按鈕

## 睦州忠義急援正確順序

1. 戴宗傳遞軍民分路急令
2. 安道全分設三處傷兵站
3. 花榮射斷錯誤追擊烽燈
4. 張順、李俊護送水路傷民
5. 盧俊義封退路、宋江受降

線索、急援軍紀、驛站及軍醫營等級，都會改變初始軍勢與混亂警戒。最後一步在前四步未完成，或敵陣尚未削弱到指定程度時會維持鎖定。

## 戴宗專屬技能

### 神行甲馬

造成傷害、恢復豪氣、看破下一擊，並提高下一次普通攻擊的重創機率。

### 飛符急救

接通安道全救護線，恢復氣血、建立守勢、削弱敵方武力，適合傷兵戰與首領戰。

## 原著傷亡／協同急援分歧

完成至少三項急援線索、將軍醫營升至 Lv.2，或維持足夠急援軍紀，可讓戴宗與安道全接通撤傷路線，降低可避免的傷亡。

準備不足時可閱讀原著傷亡錄，再返回軍議補查線索、強化軍醫營並重新挑戰，不會永久失去新英雄。

## 快速整備

遊戲左側主選單新增「整備」：

- **目前英雄休養**：消耗 8 兩，立即補滿目前英雄氣血與豪氣。
- **全寨整備**：完成江州劫法場後開放，消耗 1 份糧草恢復所有已解鎖英雄。
- **前往梁山建設**：直接開啟山寨建築，不必先返回特定地圖。

## 執行方式

直接開啟 `index.html` 即可遊玩。PWA 安裝與離線快取建議透過 HTTPS 或本機 HTTP 伺服器執行。

## GitHub Pages 部署

請把下列內容直接放在 repository 根目錄：

```text
index.html
styles.css
game.js
manifest.webmanifest
service-worker.js
README.md
TEST_REPORT.md
assets/
```

不要只上傳外層 `water-margin-rpg-v2.7.0` 資料夾，否則 GitHub Pages 可能找不到首頁。

## 更新注意事項

Service Worker 快取名稱已更新為 `liangshan-rpg-v2.7.0`。覆蓋新版後，請使用 `Ctrl + F5` 強制重新整理；已安裝成 PWA 時，請完全關閉後重新開啟。

## 存檔

遊戲沿用既有存檔鍵：

```text
liangshan-rpg-save-v1
```

載入舊存檔時會自動補入戴宗、安道全、第十六回任務、急援線索、睦州軍略及軍醫營，不會清除既有英雄、裝備、羈絆、建築、資源與前十五回進度。
