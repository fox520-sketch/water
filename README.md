## 梁山公議定法正確順序

1. 樂和公開案由與證人名單
2. 蔣敬封存沒收財物與賠償
3. 蕭讓整理證詞與巡寨紀錄
4. 裴宣三審覆核並隔離衝突
5. 宋江公布判決理由與申訴期限

前四步尚未完成，或私刑假證封鎖尚未削弱到指定程度時，最後的公開判決會維持鎖定。

## 裴宣專屬技能

### 鐵面戒尺

造成傷害、削弱敵方武力，並建立短暫防護。適合在敵方攻勢尚強時先穩住場面。

### 三審定案

造成強力傷害、削弱敵方筋骨，並提高下一次攻擊的重創機率；有機會讓敵方號令暫停一回合。

## 執行方式

直接開啟 `index.html` 即可遊玩。PWA 安裝與離線快取建議透過 HTTPS 或本機 HTTP 伺服器執行。

## GitHub Pages 部署

請把下列內容直接放在 repository 根目錄：

```text
index.html
styles.css
game.js
manifest.webmanifest
service-worker.js
README.md
TEST_REPORT.md
assets/
```

不要只上傳外層 `water-margin-rpg-v3.0.0` 資料夾。

## 更新注意事項

Service Worker 快取名稱已更新為 `liangshan-rpg-v3.0.0`。覆蓋新版後請按 `Ctrl + F5` 強制重新整理；已安裝成 PWA 時，請完全關閉後重新開啟。

## 存檔

遊戲沿用既有存檔鍵：

```text
liangshan-rpg-save-v1
```

載入舊存檔時會自動補入裴宣、樂和、第十九回任務、公議線索、梁山公議定法、忠義公議堂與相關旗標，不會清除既有英雄、裝備、羈絆、建築、資源及前十八回進度。
