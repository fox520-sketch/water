# 水滸英雄傳：梁山風雲 v7.3.0

## 梁山英雄覺醒與戰略回合版

這是一款可直接在瀏覽器遊玩的繁體中文長篇 RPG，包含 108 回完整英雄主線、自由編隊、英雄養成、裝備鍛造、梁山寨建設與離線 PWA。

## v7.3.0 核心更新

### 1. 正式回合與速度行動系統

- 我方與敵方全部單位依速度排列行動條。
- 每個存活單位每回合只會行動一次。
- 全部單位完成行動後，才結算中毒、燃燒、流血與狀態持續時間。
- 神行、遲緩、馬廄、站位與裝備速度會影響下一回合行動順序。
- 戰鬥支援 ×1、×2、×3 速度與自動戰鬥。

### 2. 首領強制換階與差異招式

首領在 70% 與 35% 氣血時會強制停在門檻並立即換階，不能被一次高傷害跳過。

六種首領機制：

- 鐵甲護身：護盾、反擊、全隊盾擊。
- 困獸暴怒：提速、增傷、第三階段連擊。
- 邪陣回生：回復、驅散、週期性再生。
- 召集援兵：兩次換階召來不同援軍。
- 毒霧侵體：範圍毒霧與強化毒傷。
- 借力反震：技能反震與第三階段強化反震。

### 3. 108 名英雄專屬技能與覺醒

- 108 個不重複專屬技能名稱。
- 108 個不重複專屬被動名稱。
- 108 個不重複覺醒名稱。
- 以 12 種主效果 × 9 種副效果組成 108 組不重複戰法效果。
- 英雄達 20 級、完成自己的主角章回並消耗 8 份精華後可覺醒。
- 覺醒會強化技能係數與專屬副效果。

### 4. 分支技能樹

每名英雄有三系技能樹，每系兩條互斥路線、最高 3 級：

- 武勇：怒勢／連戰。
- 守備：鐵壘／反守。
- 謀略：控局／行氣。

可支付銀兩重置全部技能點並重新配點。

### 5. 三套編隊與戰前敵情

- 可保存三套四人隊伍。
- 每隊包含前排兩人、後排兩人。
- 情報所會顯示敵人數量、首領機制與推薦英雄類型。
- 章回主角若不在四人隊伍，會以第五名客將加入。
- 主角客將存活完成首領戰可取得專屬成就。

### 6. 手動裝備與套裝效果

- 可手動為英雄選擇武器與防具。
- 選裝畫面會顯示目前裝備、戰力差異、稀有度與套裝。
- 支援鍛造、強化至 +5、分解與一鍵最佳裝備。
- 五種二件套：伏虎、雲龍、混江、回春、鐵壁。

### 7. 章回劇情與玩法差異化

依章回類型提供十種故事抉擇：

- 英雄決斷
- 公斷抉擇
- 軍陣抉擇
- 護送路線
- 潮勢抉擇
- 救護優先
- 安民方案
- 交易處置
- 山野路線
- 潛行方案

不同選擇會改變敵方攻防、速度、敵人數量、護盾、狀態、藥品、素材或銀兩獎勵。108 回使用四種不同的查驗、軍略、轉折與戰鬥排列。

### 8. IndexedDB 與輪替備份

- IndexedDB 為主要存檔。
- localStorage 保留相容鏡像。
- 最近五份備份自動輪替。
- 完成章回、完成首領戰、匯入存檔與 PWA 更新前會建立備份。
- 存檔管理可手動備份、還原、匯出與匯入。
- 可承接 v7.2.0 的完成紀錄、銀兩、英雄、裝備、建設、編隊與章回進度。

## 執行方式

### Windows 相容 ZIP

1. 解壓縮 `Liangshan_v7.3.0_Windows.zip`。
2. 進入 `Liangshan_v7.3.0` 資料夾。
3. 雙擊 `index.html`。

直接開啟可遊玩，但瀏覽器安全規則不允許 `file://` 使用 Service Worker，因此離線 PWA 安裝與更新提示需部署到 HTTPS 網站或以 localhost 執行。

### 免解壓單一 HTML

直接開啟 `Liangshan_v7.3.0_Standalone.html`。此版本適合單機遊玩，不包含 Service Worker 離線更新功能。

### 本機 PWA 測試

在本資料夾上一層啟動靜態伺服器，例如：

```bash
python -m http.server 8000
```

再開啟：

```text
http://localhost:8000/Liangshan_v7.3.0/
```

## GitHub Pages 部署

本版包含：

```text
.github/workflows/pages.yml
.nojekyll
```

將 `Liangshan_v7.3.0` 資料夾內容放在 GitHub 儲存庫根目錄並推送至 `main`，再到儲存庫 Settings → Pages，將來源設為 GitHub Actions。工作流程會上傳靜態檔案並部署。

詳細步驟請看 `DEPLOY_GITHUB_PAGES.md`，驗收結果請看 `PWA_ACCEPTANCE.md`。

## 瀏覽器建議

- Windows：最新版 Chrome、Edge 或 Firefox。
- Android：最新版 Chrome。
- iPhone／iPad：最新版 Safari；PWA 與儲存限制依 iOS 版本而異。

## 檔案說明

- `index.html`：遊戲入口。
- `game.js`：遊戲、戰鬥、養成與存檔系統。
- `chapters.js`／`chapters.json`：108 回資料。
- `styles.css`：水墨、深色、電子紙與手機版樣式。
- `manifest.webmanifest`：PWA 資訊。
- `service-worker.js`：離線快取與更新。
- `TEST_REPORT.md`：測試報告。
- `PWA_ACCEPTANCE.md`：PWA 驗收報告。
- `CHANGELOG.md`：版本更新紀錄。
