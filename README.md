# 水滸英雄傳：梁山風雲 v2.4.0

以《水滸傳》重要章回重新編寫的單機網頁 RPG。遊戲可直接在瀏覽器執行，支援電腦與手機、本機存檔、語音播報、PWA 離線安裝，以及水墨、OLED 深色、黑白電子紙三種顯示模式。

## v2.4.0「河北征田虎・幻魔破陣」

雁門戰後，梁山奉命轉戰河北。玩家先以宋江整頓護糧路線，再切換瓊英制止田虎親軍強徵民糧；進入襄垣幻霧谷後，必須收集線索、結識喬道清，並依正確順序完成五階段「襄垣破幻」軍略。攻入昭德府後，最終目標不是掠城，而是開啟避難門、發還種糧與田契。

## 瓊英專屬技能

### 飛星流光

消耗 9 點豪氣，以飛石連取敵人穴位，削弱武力並有機會震懾敵手。

### 梨花迴槍

消耗 14 點豪氣，以槍花護身後反刺，造成重擊並架起反擊之勢。

## 襄垣破幻軍略

必須依序執行：

1. 公孫勝踏罡定八門方位
2. 戴宗疾行斷開埋符火線
3. 花榮射落霧中旗幡
4. 張清飛石擊鐘醒軍
5. 瓊英開啟真城門、先護送百姓

錯誤或準備不足會使梁山軍勢下降、迷障加深。沿途軍紀、幻霧線索、河北軍糧及驛站等級，都會影響攻略難度。

## 執行方式

### 直接開啟

解壓縮後開啟 `index.html` 即可遊玩。部分瀏覽器對本機檔案的 Service Worker、PWA 與語音權限有限，正式使用建議部署到 HTTPS 網站。

### GitHub Pages

將壓縮檔內以下內容直接放在儲存庫最上層：

```text
index.html
styles.css
game.js
manifest.webmanifest
service-worker.js
README.md
TEST_REPORT.md
assets/
```

不要只上傳外層 `water-margin-rpg-v2.4.0` 資料夾，否則 GitHub Pages 可能找不到首頁。

## 更新 GitHub Pages 後的快取處理

本版 Service Worker 快取名稱已更新為 `liangshan-rpg-v2.4.0`。覆蓋新版檔案後：

1. 重新整理網站一次。
2. 若仍看到舊版，使用 `Ctrl + F5` 強制重新整理。
3. 已安裝成 PWA 時，完全關閉遊戲後再重新開啟。
4. 不要清除網站資料，否則 LocalStorage 存檔也會被刪除。

## 存檔

遊戲使用瀏覽器 LocalStorage，存檔鍵為：

```text
liangshan-rpg-save-v1
```

v2.3.0 存檔載入後會自動補入：

- 瓊英角色與專屬裝備欄
- 喬道清同伴資料
- 第十三回任務與旗標
- 河北護糧、軍紀及幻霧線索
- 襄垣破幻軍略資料
- 梁山驛站 Lv.1

原有英雄、裝備、行囊、羈絆、派系聲望、山寨建設及遠征紀錄均會保留。

## 主要檔案

- `index.html`：頁面結構與遊戲模板
- `styles.css`：桌面、手機及三種顯示模式
- `game.js`：劇情、戰鬥、軍略、存檔、語音及建設系統
- `manifest.webmanifest`：PWA 名稱、顏色與圖示設定
- `service-worker.js`：離線快取與舊快取更新
- `TEST_REPORT.md`：本版檢查及測試紀錄
- `assets/`：PWA 圖示
