# 水滸英雄傳：梁山風雲 v5.1.0

章回式單機網頁 RPG。本版延續 v5.0.0 的百信安傳制度，新增第四十回「笑面虎聽訴・百訴安解」，讓梁山公共治理由消息可達延伸至申訴收件、分流保密、事證勘驗、自願調解、覆議回告、緊急救濟與反報復保護。

## v5.1.0 新增內容

- 第四十名主角「笑面虎・朱富」
- 朱富雙技能：「笑面虎聽訴」、「四案安解」
- 新同伴「青眼虎・李雲」與「青眼虎護證」援護
- 第四十回完整主線：拒收失件、冒名撤訴、逼迫私和、偏袒調解、覆議受阻及事後報復
- 四項申訴查驗與五階段「水泊百訴安解」軍略
- 三場主線戰鬥及百訴安解演武
- 新增百訴安解署、安心申訴站、百姓申訴踏勘場及百訴安解演武場
- 新增專屬武器、防具、登訴收件總冊、勘證覆議護訴簿及百訴安解約
- 四十英雄譜、聚義座次、總成果、PWA 描述及版本資訊同步更新
- 強化申訴流程：收件編號、承辦期限、敏感案件保密、證物交付鏈、利害迴避、覆議及反報復追蹤

## 存檔相容

- 支援 v1.0.0～v5.0.0 舊存檔自動升級
- 舊存檔會自動補入朱富英雄資料、李雲同伴資料、專屬裝備、第四十回任務、旗標、戰鬥狀態與百訴安解署
- v5.0.0 已完成第三十九回的存檔，可直接從章回結尾或百信安傳演武場開啟第四十回

## 使用方式

直接開啟 `index.html` 即可遊玩。若部署至 GitHub Pages，請將本壓縮檔內所有檔案上傳至同一儲存庫目錄。

Service Worker 快取名稱：`liangshan-rpg-v5.1.0`。
