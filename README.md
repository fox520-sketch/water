# 水滸英雄傳：梁山風雲 v7.1.0

## 百八英雄深度玩法版

本版以 v7.0.0「完整章回版」為基底，保留第一回至第一百零八回，並完成七項核心玩法改造。

## 啟動方式

1. 解壓縮 ZIP。
2. 直接開啟根目錄的 `index.html` 即可遊玩。
3. 若要使用 PWA 安裝、離線快取及新版本更新提示，請部署到 GitHub Pages、Firebase Hosting 或其他 HTTPS 網站。

## 七項核心更新

### 1. 章回進度安全保護

- 每個章回都有獨立進行中暫存。
- 切換章回會保留原進度。
- 點選已有進度的章回時，可選擇「繼續本回」或「重新挑戰」。
- 重新挑戰前一定顯示確認視窗。
- 完成章回後重新挑戰，不會覆蓋原最佳紀錄，除非新分數更高。

### 2. 梁山銀兩商店

- 金瘡藥補給：每份 120 銀兩。
- 備用藥品存入梁山倉庫，可在章回內領用。
- 每回最多攜帶 5 份金瘡藥。
- 三件行裝皆可永久升至 5 級：
  - 護心鏡：提高守勢回血。
  - 軍略旗：降低制度絕技豪氣消耗。
  - 公義印：提高戰鬥銀兩獎勵。

### 3. 108 名英雄專屬戰法

108 名主角都有不同的專屬戰法名稱，依章回屬性分為十種角色定位：

- 猛將
- 斷案
- 守將
- 疾行
- 水軍
- 醫護
- 軍師
- 巧匠
- 獵蹤
- 奇襲

不同定位會實際影響追擊、穿防、護盾、回氣、潮勢、治療、制度絕技、暴擊或閃避。

### 4. 六種同伴援護與首領機制

同伴援護類型：

- 合擊破甲
- 護命回春
- 奇策回氣
- 捨身護陣
- 斷勢封招
- 聚義得財

最終首領機制：

- 鐵甲護身
- 困獸暴怒
- 邪陣回生
- 召集援兵
- 毒霧侵體
- 借力反震

### 5. 交錯故事流程

每回改為 13 步交錯流程：

1. 查驗一
2. 查驗二
3. 軍略一
4. 前哨戰
5. 查驗三
6. 軍略二
7. 軍略三
8. 查驗戰
9. 查驗四
10. 軍略四
11. 軍略五
12. 首領戰
13. 章回結算

不再先按完全部查驗與軍略後才連續戰鬥。

### 6. 章回篩選

章回總覽新增：

- 未完成
- 非 S 級
- 最近遊玩

同時保留篇章篩選與文字搜尋。

### 7. PWA 更新提示

部署於 HTTPS 網站後，發現新版 Service Worker 時會顯示：

- 查看更新內容
- 立即更新
- 稍後更新

按下立即更新前會先儲存目前進度，更新完成後自動重新載入。

## 存檔承接

本版沿用存檔鍵：

`liangshan-rpg-complete-v7`

首次讀取 v7.0.0 存檔時會：

1. 將原始存檔備份至遷移備份鍵。
2. 保留完成紀錄、銀兩、目前章回及偏好。
3. 將原本單一進行中章回轉成多章回暫存格式。
4. 補上商店、備用藥品及裝備等級欄位。

v4.5.0 與 v6.2.0 的舊存檔承接功能仍然保留。
