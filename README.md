# 水滸英雄傳：梁山風雲 v4.0.0

章回式單機網頁 RPG，以《水滸傳》人物與事件為基礎進行互動式改編。本版延續 v3.9.0 的水泊百宿安行制度，新增第二十九回「菜園封運與百包安寄」，並作為二十九英雄與寄運公證系統的里程碑版本。

## v4.0.0「第二十九回・菜園封運與百包安寄」

- 新增第二十九名主角「菜園子・張青」
- 新增張青技能「菜園封籤」與「四路接運」
- 新增同伴「母大蟲・顧大嫂」及援護技能「母大蟲護運」
- 新增寄收身份、重量封籤、腳夫路線、失物理賠四項寄運線索
- 新增五階段「水泊百包安寄」軍略
- 新增掉包黑腳行巡丁、黑腳牙行護院、寄利掮客與黑腳豪商等敵人
- 新增「梁山寄運公證所」及四處輿圖地點
- 新增「百包失序／公開百包安寄」分歧劇情
- 新增三項章回收藏及百包安寄演武場
- 二十九位英雄可於完成各自章回後自由切換

## 本版修正

- 補齊菜園子張青在英雄切換、章回編號、返回據點與輿圖旅行的判定
- 更新遊戲指南、版本介紹、總成果及梁山建設，加入百包安寄與寄運公證所
- 統一首頁、Manifest、Service Worker 與 PWA 快取為 v4.0.0
- 延續第 23～29 名英雄章回編號、返回據點與輿圖自動切換回歸檢查
- 完整調查四項寄運線索後，可依正確順序完成公開追索與理賠

## 遊戲特色

- 二十九回完整主線與二十九名可操作英雄
- 回合制戰鬥、角色專屬技能及同伴援護
- 調查線索、軍略推演、分歧劇情及重複演武
- 梁山建設、英雄譜、江湖輿圖、快速整備及本機存檔
- 水墨宣紙、深色及黑白電子紙三種顯示模式
- 可選語音播報與 PWA 離線遊玩
- 純 HTML、CSS、JavaScript，不需要資料庫或後端伺服器

## GitHub Pages 部署

1. 解壓縮 ZIP。
2. 將 `index.html`、`game.js`、`styles.css`、`manifest.webmanifest`、`service-worker.js`、說明文件及 `assets` 資料夾直接上傳至儲存庫根目錄。
3. 不要只上傳外層 `water-margin-rpg-v4.0.0` 資料夾，否則 GitHub Pages 可能找不到首頁。
4. 發布後按 `Ctrl + F5` 強制重新整理。

## PWA 快取

Service Worker 快取名稱為 `liangshan-rpg-v4.0.0`。覆蓋新版檔案後請強制重新整理；若已安裝為 PWA，請完全關閉後重新開啟，以載入新版快取。

## 舊存檔升級

v4.0.0 會自動補齊菜園子張青主角、母大蟲顧大嫂、第二十九回任務、寄運公證所、四項寄運線索及百包軍略欄位。舊版英雄、裝備、同伴、建築與章回進度均會保留。

存檔使用瀏覽器 LocalStorage；清除網站資料或更換瀏覽器、裝置，不會自動同步原有進度。
