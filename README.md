# 水滸英雄傳：梁山風雲 v2.2.0

純 HTML、CSS、JavaScript 製作的章回式單機網頁 RPG，可直接部署至 GitHub Pages。

## v2.2.0「兩贏童貫・三敗高俅」

- 新增第十一回完整章回
- 新增第十一名主角「沒羽箭張清」
- 新增張清技能「沒羽飛石」「飛蝗連珠」
- 新增同伴「混江龍李俊」與水戰援護
- 新增童貫十節度前鋒、東昌飛石騎隊、殿前司監軍及高俅旗艦首領戰
- 新增五階段「水泊鎖艦」軍略：測水、誘敵、斷纜、借霧、飛石
- 新增水寨船塢建設與水路巡護遠征
- 新增十一英雄譜與座次
- 保留語音播報、深色模式、電子紙模式、PWA 與本機存檔
- 相容 v1.0～v2.1 存檔

## 啟動方式

直接開啟 `index.html` 即可遊玩。PWA 與離線快取建議透過 HTTPS 或本機 HTTP 伺服器執行。

## GitHub Pages

將下列內容直接上傳至儲存庫根目錄：

- `index.html`
- `styles.css`
- `game.js`
- `manifest.webmanifest`
- `service-worker.js`
- `assets/`
- `README.md`
- `TEST_REPORT.md`

不要只上傳外層 `water-margin-rpg-v2.2.0` 資料夾，否則 GitHub Pages 可能找不到首頁。
