# 水滸英雄傳：梁山風雲 v3.2.0

章回式單機網頁 RPG，可直接部署至 GitHub Pages，也支援安裝為 PWA 與離線遊玩。

本版新增：

- 第二十一回完整主線「玉臂刻信・水泊通憑」
- 第二十一名可操作英雄「玉臂匠・金大堅」
- 金大堅專屬技能「玉臂驗印」與「四路同憑」
- 新同伴「玉幡竿・孟康」與援護技能「玉幡通途」
- 四項通憑調查線索：通憑底冊、印版序號、關津貨單、四路見證
- 五階段「水泊公信通憑」軍略
- 三場主線戰鬥：偽路引關卡巡丁、私卡貨棧護院、路引牙行與關卡豪商
- 「通行失信／公開通憑」分歧劇情
- 新建築「梁山通憑印務所」
- 四處新地點：水泊通憑關、梁山通憑印務所、金沙灘商旅渡、通憑護路演武場
- 二十一位英雄自由切換
- 三項新收藏：水泊通憑總冊、關津貨運公帳、水泊公信通行約
- 完整支援 v1.0～v3.1.0 舊存檔自動升級

## 水泊公信通憑正確順序

1. 金大堅編列一憑一號
2. 蕭讓四處留存印樣底冊
3. 蔣敬公開關津退費帳
4. 孟康標定舟橋與替代貨路
5. 宋江建立補發與申訴

未依順序操作時，後續按鈕會保持鎖定；完成全部五步後才會進入最終首領戰。

## 主要檔案

- `index.html`：遊戲頁面與介面模板
- `styles.css`：桌面、手機、深色與電子紙顯示樣式
- `game.js`：劇情、戰鬥、存檔、軍略與 PWA 操作邏輯
- `manifest.webmanifest`：PWA 安裝資訊
- `service-worker.js`：離線快取
- `assets/`：遊戲圖示
- `TEST_REPORT.md`：本版測試項目與結果

## GitHub Pages 部署

1. 解壓縮 ZIP。
2. 將 ZIP 內的所有檔案與 `assets` 資料夾直接上傳到 GitHub 儲存庫根目錄。
3. 在 GitHub 儲存庫的 **Settings → Pages** 選擇從主要分支根目錄部署。
4. 發布完成後按 `Ctrl + F5` 強制重新整理。

不要只上傳外層 `water-margin-rpg-v3.2.0` 資料夾，否則 GitHub Pages 可能找不到首頁。

## PWA 更新

Service Worker 快取名稱為 `liangshan-rpg-v3.2.0`。覆蓋新版後請按 `Ctrl + F5`；已安裝成 PWA 時，請完全關閉後重新開啟。

## 存檔相容性

遊戲沿用 `liangshan-rpg-save-v1` 本機存檔鍵。載入舊存檔時會自動補入金大堅主角、孟康同伴、第二十一回任務、通憑線索、水泊公信通憑、通憑印務所與相關旗標，不會清除既有英雄、裝備、羈絆、建築、資源及前二十回進度。

## 操作提醒

- 進度保存在目前瀏覽器的 Local Storage。
- 清除網站資料會同時清除存檔。
- 右上角可切換音效、語音播報及顯示模式。
- 手機版江湖輿圖採可捲動雙欄清單，避免大量地點重疊。
