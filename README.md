# 水滸英雄傳：梁山風雲 v2.9.0

章回式單機網頁 RPG，以 HTML、CSS 與 JavaScript 製作，可直接部署到 GitHub Pages，支援 PWA、離線快取、語音播報與瀏覽器本機存檔。

## v2.9.0「第十八回・忠義安業與梁山新生」

本版新增：

- 第十八回完整主線「忠義安業・梁山新生」
- 第十八名可操作英雄「聖手書生蕭讓」
- 蕭讓專屬技能「鐵畫銀鉤」「金印辨契」
- 原始田契、家眷戶籍、義糧出納與水泊界圖四項安業線索
- 五階段「梁山安民復寨」軍略
- 新同伴「神算子蔣敬」與「神算清帳」援護
- 水泊侵契巡檢、豪強契庫護院、侵產胥吏與豪強牙人首領戰
- 「安置失敗／公開安業」可改寫分歧
- 新建築「梁山安業簿房」
- 安業護戶演武場
- 十八英雄自由切換
- v1.0～v2.8.0 舊存檔相容

## 梁山安民復寨正確順序

1. 戴宗通知返鄉戶與家眷
2. 蔣敬清點義糧與撫卹銀
3. 蕭讓比對田契、戶籍與界圖
4. 朱武布水陸護戶陣
5. 宋江公開梁山安業總簿

前四步尚未完成，或侵契封鎖尚未削弱到指定程度時，最後的公開安業會維持鎖定。

## 蕭讓專屬技能

### 鐵畫銀鉤

造成傷害、削弱敵方筋骨、恢復少量豪氣，並提高下一次普通攻擊重創機率。

### 金印辨契

造成強力傷害、削弱敵方武力、建立守勢與兩回合防護，並有機會封駁敵方號令一回合。

## 執行方式

直接開啟 `index.html` 即可遊玩。PWA 安裝與離線快取建議透過 HTTPS 或本機 HTTP 伺服器執行。

## GitHub Pages 部署

請把下列內容直接放在 repository 根目錄：

```text
index.html
styles.css
game.js
manifest.webmanifest
service-worker.js
README.md
TEST_REPORT.md
assets/
```

不要只上傳外層 `water-margin-rpg-v2.9.0` 資料夾。

## 更新注意事項

Service Worker 快取名稱已更新為 `liangshan-rpg-v2.9.0`。覆蓋新版後請按 `Ctrl + F5` 強制重新整理；已安裝成 PWA 時，請完全關閉後重新開啟。

## 存檔

遊戲沿用既有存檔鍵：

```text
liangshan-rpg-save-v1
```

載入舊存檔時會自動補入蕭讓、蔣敬、第十八回任務、安業線索、梁山安民復寨軍略與安業簿房，不會清除既有英雄、裝備、羈絆、建築、資源與前十七回進度。
