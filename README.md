# 水滸英雄傳：梁山風雲 v3.3.0

章回式單機網頁 RPG，以《水滸傳》人物與事件為基礎進行互動式改編。本版延續 v3.2.0 的水泊通憑制度，加入第二十二回「玉幡定載與百舸共運」。

## v3.3.0「第二十二回・玉幡定載與百舸共運」

水泊通憑已讓商旅可以跨處驗證，渡口卻出現超載私渡、偽造吃水線、班次壟斷與事故推諉。孟康丈量船骨、吃水與實際載重，侯健統一載重、停航、風浪與救援號旗，眾頭領共同建立公開班次、運價、救生航線及事故賠償制度。

### 本版新增

- 第二十二名可操作英雄「玉幡竿・孟康」
- 孟康專屬技能「玉幡定載」與「百舸共航」
- 新同伴「通臂猿・侯健」及援護技能「通臂號旗」
- 四項舟運線索：船籍修造、吃水載重、班次運價、風浪救援號旗
- 五階段「水泊百舸共運」軍略
- 三場主線戰鬥與百舸共運演武
- 「舟運失序／公共舟運」分歧路線
- 新建築「梁山百舸公運署」
- 四處新地點：金沙灘驗載埠、梁山百舸公運署、水泊百舸渡、百舸共運演武場
- 三項新收藏：水泊舟船總冊、渡運班次與承載簿、水泊百舸共運約
- 二十二位英雄自由切換
- 支援 v1.0～v3.2.0 舊存檔自動升級

### 本版修正

- 補齊第 18～22 回戰敗與退走的正確返回地點
- 修正聚義座次說明仍顯示二十位英雄

## 遊玩方式

1. 直接開啟 `index.html`，或部署至 GitHub Pages。
2. 按「新開篇章」開始遊戲；已有存檔可按「續讀存檔」。
3. 遊戲進度儲存在瀏覽器本機儲存空間，不會上傳伺服器。
4. 可使用角色、同伴、行囊、任務、輿圖、快速整備與梁山建設等功能。
5. 支援淺色、深色及黑白電子紙顯示模式。

## GitHub Pages 部署

請將下列檔案與資料夾直接放在儲存庫根目錄：

- `index.html`
- `styles.css`
- `game.js`
- `manifest.webmanifest`
- `service-worker.js`
- `assets/`
- `README.md`

不要只上傳外層 `water-margin-rpg-v3.3.0` 資料夾，否則 GitHub Pages 可能找不到首頁。

## 更新與快取

Service Worker 快取名稱為 `liangshan-rpg-v3.3.0`。覆蓋新版檔案後，請按 `Ctrl + F5` 強制重新整理。若已安裝成 PWA，請完全關閉後重新開啟，以載入新版快取。

## 存檔相容性

v3.3.0 會自動補齊孟康、侯健、第二十二回任務、百舸公運署、舟運線索與軍略欄位。舊版英雄、裝備、同伴、建築及章回進度會保留。
