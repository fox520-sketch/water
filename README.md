# 水滸英雄傳：梁山風雲 v3.7.0

章回式單機網頁 RPG，以《水滸傳》人物與事件為基礎進行互動式改編。本版延續 v3.6.0 的水泊四隅聯防，新增第二十六回「紫髯辨疫與水泊牧護」。

## v3.7.0「第二十六回・紫髯辨疫與水泊牧護」

- 新增第二十六名可操作英雄「紫髯伯・皇甫端」
- 新增皇甫端專屬技能「紫髯辨疫」與「四區牧護」
- 新增同伴「操刀鬼・曹正」及援護技能「操刀分檢」
- 新增畜籍症候、飼料水源、隔離清消、屠檢流向四項線索
- 新增五階段「水泊人畜安康」軍略
- 新增三場第二十六回主線戰鬥及人畜安康演武
- 新增「梁山牧護防疫院」與四處輿圖地點
- 新增畜籍防疫總冊、飼水檢驗隔離簿及人畜安康約三項收藏
- 新增牧護失序與公開防疫分歧路線
- 二十六位英雄自由切換
- 完整保留 v1.0～v3.6.0 舊存檔

## 同步改善

- 旅行至第二十六回地點時可自動開啟或切換皇甫端
- 章回成果、聚義座次、梁山建設與演武統計更新為二十六英雄
- 江湖輿圖保留桌面四欄、平板三欄、手機雙欄卡片排列
- 更新首頁、遊戲指南、版本說明、Manifest 與 PWA 離線快取

## 執行方式

直接開啟 `index.html` 即可遊玩。為確保 PWA、語音與離線快取正常，建議透過 GitHub Pages 或本機 HTTP 伺服器執行。

## GitHub Pages 部署

1. 解壓縮 ZIP。
2. 將 `index.html`、`game.js`、`styles.css`、`manifest.webmanifest`、`service-worker.js`、說明文件及 `assets` 資料夾直接上傳至儲存庫根目錄。
3. 不要只上傳外層 `water-margin-rpg-v3.7.0` 資料夾，否則 GitHub Pages 可能找不到首頁。
4. 部署後按 `Ctrl + F5` 強制重新整理。

## PWA 快取

Service Worker 快取名稱為 `liangshan-rpg-v3.7.0`。覆蓋新版檔案後請強制重新整理；若已安裝為 PWA，請完全關閉後重新開啟，以載入新版快取。
